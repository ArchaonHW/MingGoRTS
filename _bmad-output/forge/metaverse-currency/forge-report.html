鍛造報告 — 元宇宙虛擬貨幣

結果

原始想法「元宇宙 + 玩賺虛擬貨幣」經壓力測試後硬化為:鏈上存證 + NFT 收藏層 — 測試網代幣、本地鏈原語、replay 驗證鑄幣、外部 relayer 整合。「主網真錢 P2E」被否決,理由見下。

定案決策

  • 幣種:測試網代幣(Sepolia/Anvil)— 真實區塊鏈技術,幣值為零
  • 架構:本地鏈(Merkle tree、鑄幣規則)+ Merkle root 錨定測試網
  • 鑄幣:replay 驗證結算鑄幣 + 稀有成就鑄幣(雙軌)
  • 用途:鑄 NFT 收藏品(章回箋、本草圖鑑、名將檔案)
  • 整合:外部 relayer,遊戲只輸出 versioned JSON claim;引擎零網路
  • 落地:Epic 11,走 correct-course 正規流程

否決項

  • 主網真錢 P2E — 單機無交易對手、無經濟體、法規風險、違非商業定位
  • 引擎內建 RPC — 引擎無網路層,私鑰入引擎風險高
  • 玩家間資產交易 — 需多人環境才有意義

存活弱點(已接受)

  • 全 client-side 無真防作弊 — 可接受:測試網零幣值,防作弊是叙事而非安全保證
  • 一人開發、sprint 進行中 — Epic 11 需控制規模,建議最小切片先行
壓力測試參與:Cloud Dragonborn(遊戲架構師 · 引擎能力/架構邊界)、老練(生成人格 · 代幣經濟質疑者 — 交易對手問題、無底水龍頭)。
詳細決策見 forged-idea.md。
