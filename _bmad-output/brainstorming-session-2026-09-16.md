## Brainstorming Approach

**Selected Mode:** YOLO（全技法驅動）

**Techniques Available:**
Genre Mashup / Core Loop / MDA / Player Fantasy Mining / Verbs Before Nouns /
Failure State Design / Progression Curve / Emotion Targeting / What-If /
Remix Existing Game / Constraint Box / Emergence Engineering /
Ludonarrative Harmony / Reward Schedule Architecture / Morphological Analysis /
SCAMPER / Economy Balancing / Toy Before Game / Anti-Game Design /
First Principles / Social Dynamics / Spectator Design

**Focus Areas:**
- 回合制 RPG × 即時戰略戰鬥的縫合切點（何時回合、何時即時、誰控制什麼）
- 玩家動詞：「佈署」vs「介入」vs「微操」的光譜定位
- RPG 成長（角色/裝備/羈絆）如何映射到 RTS 單位與戰場
- 失敗設計：回合玩家 vs 即時玩家的容錯期待落差
- 引擎可行性：MingGoRTS/PotatoEngine 現有 ECS、事件、物理、輸入能撐什麼玩法

**Ideation 回合規劃（Party Mode 產出）：**
1. Core Loop 切分 —— 回合層產出「命令」還是「資源」？
2. 玩家動詞 —— 指揮官視角 vs 微操視角的主從
3. 失敗與犧牲 —— 有名有姓的單位戰損作為敘事代價
4. Mashup 狂想 —— What-If / Remix 打開邊界
5. 原型收斂 —— 最小可行戰鬥原型定義

**Party Mode / Advanced Elicitation 產生的設計洞察：**
- 切點光譜：全事前規劃（自走棋端）← Gambit/腳本式（潛在甜區）→ 全微操（純 RTS 端）
- 核心二分：回合層產出「命令」vs 產出「資源」
- 三拍情緒循環：掌控（回合運籌）→ 懸疑/心痛（即時執行）→ 哀悼與重建（戰後回合）
- 突變株點子：FF12 Gambit × RTS＝玩家寫 AI 腳本打仗的程式對戰 RPG
- 失敗機制構想：即時劣勢彈回回合層做「斷後犧牲」決策——機制即主題

**Advanced Elicitation 第二輪洞察：**
- 形態四軸矩陣（設計空間地圖，256 種組合）：
  - 誰下指令：玩家本人 / AI 腳本 / NPC 副官（玩家只控英雄）
  - 時間流動：永遠即時 / 指令階段暫停 / 限次子彈時間 / 慢速即時
  - 什麼持續：角色養成 / 傷亡名單 / 裝備領地 / **敵方學習你的戰術**
  - 失敗落地：讀檔 / 永久死亡 / 撤退保殘部 / **戰敗推進劇情**
- 第一性原理推論：回合層 = 深思區，只放需要 deliberation 的決策
  （戰前情報、編成、doctrine 撰寫、外交取捨；即時做也沒差的不放）
- 反設計突變株：戰敗解鎖敘事線（流亡/被俘營救/游擊）——輸也是分岔點
- Doctrine 排程作為玩具本體（Opus Magnum 式時間軸編排），
  天生可觀賞可分享——「匯出 doctrine 給朋友挑戰」
- Gambit 式路線的最大缺口：RPG 玩家「想微操但做不到」的初期沮喪期

**Advanced Elicitation 第三輪洞察（系統層 × 引擎現實）：**
- 回合資源經濟四幣種：情報 / 指令槽 / 士氣 / 指揮點數(CP)
  —— 情報與指令槽互斥（多偵查就少寫腳本）製造核心取捨
- 成長綁動詞：升級解鎖腳本表達力而非數值
  （單條件 → 邏輯鏈 → 跨隊聯動觸發 → 頂點解鎖 CP 即時介入）
  build 多樣性 = 指揮風格，不是屬性配點
- 引擎順勢形狀（PotatoEngine 現況反推）：
  - 無尋路 → 小隊為最小單位，squad-level flow field 即可
  - EventBus 現成 → doctrine 觸發器天然映射（OnHealthBelow30 → 動作）
  - 物理碰撞現成 → 地形互動玩法（推落石、點燃油漬、衝鋒擊飛）
- SCAMPER 突變：指令卡組化 / 腳本過熱（寫太多降精度）/
  戰後繳獲敵方 doctrine / 部署反轉（敵人先看你的陣再出牌）
- 非同步 doctrine 對戰：上傳防守腳本給朋友攻打 = 單機獲得 metagame 壽命

## Ideas Generated

**[CoreLoop #1]**: 情報即地形
_Core Loop_: 回合層花情報點揭開敵方「機率雲」部署；腳本要對付不確定性本身而非確定敵人。
_Novelty_: doctrine 品質 = 對多少敵情分支成立；戰後回放指出腳本在哪種敵情下崩潰，情報購買有方向性。

**[CoreLoop #2]**: 斷後回合
_Core Loop_: 即時潰敗時強制彈回回合層 60 秒：選斷後人員、撤退路線、放棄輜重。
_Novelty_: 戰敗是遊戲最重的決策點而非 game over；配合永久死亡成為情緒錨點。

**[CoreLoop #3]**: Doctrine 繳獲
_Core Loop_: 戰後解析敵軍殘留指揮邏輯，拆成新觸發器/動作詞彙。
_Novelty_: 敵方 doctrine 是掉落物；刷 boss = 刷腳本語法。

**[CoreLoop #4]**: 傷痕地理
_Core Loop_: 即時戰鬥在大地圖格留下永久痕跡（焦土減產/亂葬崗瘟疫/舊戰場地形沿用）。
_Novelty_: RTS 戰鬥的代價以地理寫回戰略層；玩家踩進自己造成的歷史。

**[CoreLoop #5]**: 英雄即中樞
_Core Loop_: 即時層只手操主角 RPG 小隊；軍團由 NPC 將領按性格 AI 自主作戰。
_Novelty_: 人事安排（誰守哪、性格克制）是最深戰略；保留微操手感。

**[CoreLoop #6]**: 疲勞債
_Core Loop_: 即時戰鬥的真實秒數轉換為下回合全軍疲勞 debuff。
_Novelty_: RTS 拖延產生回合層成本；戰鬥節奏被經濟壓力塑形。

**[CoreLoop #7]**: 凝滯點即資源
_Core Loop_: 「暫停下指令」是消耗品，每場 N 次，靠道具/建築/技能補充。
_Novelty_: 暫停本身進裝備欄；囤凝滯符文成為 build 抉擇。

**[CoreLoop #8]**: 心跳由敵人觸發
_Core Loop_: 敵將主動觸發凝滯點（會戰宣告→強制應戰/迴避/談判）。
_Novelty_: 時間控制權是雙方搶奪的戰鬥資源而非系統功能。

**[Doctrine #9]**: 卡槽就是命門
_Core Loop_: 5 格指令槽上限 → 必須選擇放棄防哪種死法。
_Novelty_: build 本質 =「我選擇被什麼打死」；戰敗回放顯示「你死在沒寫的那條」→ 死亡即教程。

**[Doctrine #10]**: 預演沙盤
_Core Loop_: 回合層把 doctrine 丟進模擬器跑敵情機率雲 N 次推演，回傳崩潰率與主要死因。
_Novelty_: 把「寫 code 跑測試」做進遊戲；情報 = 測試覆蓋率；打木樁練輸出 → 跑沙盤練腳本。

**[Doctrine #11]**: 連鎖卡與時間軸
_Core Loop_: 卡片可標記連鎖（佯攻完成→觸發伏兵出），多卡排成時間軸編排圖。
_Novelty_: 高階玩法 = 編排欺敵劇本，用腳本寫兵者詭道。

**[Doctrine #12]**: 破譯與反制
_Core Loop_: 敵將 doctrine 在戰場留可觀測模式；回放標記「承壓→調預備隊」→ 下一戰寫針對腳本。
_Novelty_: PvE 背板變情報工作；boss 戰 = 先輸兩場收集 doctrine 再寫反制。

**[Doctrine #13]**: 士氣作為執行變數
_Core Loop_: 同份 doctrine，高士氣嚴格執行、低士氣部隊自作主張（後撤卡被無視直接潰逃）。
_Novelty_: 腳本是意圖、部隊是執行層、中間夾人性；給「寫了腳本還輸」的挫折一個出口。

**[Doctrine #14]**: 指揮官在場
_Core Loop_: 主角隊 = 場上「可動 doctrine」，CP 介入 = 短時手操救火。
_Novelty_: 保留手感出口治微操沮喪；「主角放哪」本身是部署決策（你只能親自在一個地方）。

**[UI #15]**: 混合型介面
_Core Loop_: 地圖行為圖釘管空間（守哪/退哪）+ 卡片管觸發邏輯，兩者互相引用。
_Novelty_: doctrine 長在地形上而非抽象語法；卡槽橫列（卡組感）/時間軸（劇本感）/地圖釘（直覺感）三形式合體。

**[UI #16]**: 錄製式 doctrine
_Core Loop_: 沙盤錄製模式手操一場，系統自動轉譯操作為 doctrine 卡草稿。
_Novelty_: 微操直接變教材，玩家肌肉記憶被寫成腳本——正面解決 RPG 玩家的過渡沮喪。

**[UI #17]**: 回放標記→直接修卡
_Core Loop_: 戰敗回放是可點擊時間軸，點潰敗點→高亮「此時小隊在等指令」→一鍵回編輯器補卡。
_Novelty_: 「debug 上一場戰鬥」是核心玩法體驗；死亡→修卡的迴路零摩擦。

**[UI #18]**: 紙娃娃式整編
_Core Loop_: 小隊槽 = 兵種牌+將領牌+doctrine 模板；換兵種換可用動作詞彙（弓→齊射/火矢，騎→衝鋒/迂迴）。
_Novelty_: 組隊就是組語法；詞彙表由帶什麼兵決定。

**[Enemy #19]**: 人格即腳本傾向
_Core Loop_: 敵將三軸向量（侵略/紀律/狡詐）改 doctrine 詞彙權重而非數值。
_Novelty_: 敵我同構——敵將用你沒抽到的卡組打牌；繳獲他 = 補詞彙庫。

**[Enemy #20]**: 簽名習慣（可觀測指紋）
_Core Loop_: 敵將 2-3 條固定招牌觸發（左翼承壓必調預備隊），偵查/回放轉成情報卡（確認度%）。
_Novelty_: boss 招式表變決策表；背板變破案。

**[Enemy #21]**: 適應與反適應
_Core Loop_: 敵將對你重複使用的戰術學習（有速率上限）；你可養他的錯誤認知再突然換套路。
_Novelty_: META 層博弈——你在訓練敵方 AI 以便關鍵戰役騙它。

**[Enemy #22]**: 性格即破綻
_Core Loop_: 每種人格自帶結構漏洞（莽夫怕挑釁誘敵卡、龜將怕斷糧道繞後卡）。
_Novelty_: 敗因是「用錯牌組」而非數值不足；偵查→換牌→再戰的完整循環。

**[Enemy #23]**: 將領內鬥
_Core Loop_: 敵方多將領人格衝突產生指揮摩擦（莽夫擅自行動、雙詭將互相等）；情報顯示不合度。
_Novelty_: doctrine 可寫「挑撥」動作誘發敵指揮鏈斷裂——離間計是寫出來的。

**[Enemy #24]**: 名將養成（敵方也成長）
_Core Loop_: 敵將有履歷（戰功/敗績/被你打跑次數），老對頭進化出「反[玩家簽名戰術]」卡；擊敗傳奇敵將繳獲整副 doctrine。
_Novelty_: 敵人是活的 RPG 角色；你培養的不只隊伍還有宿敵。

## 原型規格：斷橋（最小可玩一場戰鬥）

**範圍**：回合編成（精簡）→ 一場即時戰鬥 → 戰後回放+收屍。無大地圖/外交/養成。

**戰場**：斷橋中央（兩渡口）+ 左森林（伏擊）+ 右高地（射程加成）；
3 部署區、4 行為圖釘點、2 互動地形（落石堆/油漬區）。

**我方**：槍兵（槍陣/舉盾/駐守）、弓兵（齊射/火矢/後撤）、
騎兵（衝鋒/迂迴/追擊）、主角隊（CP 手操+大招）。

**敵方**：莽夫格洛克（侵略90/紀律40/狡詐10），
簽名習慣「受挑釁→全軍突擊」「血60%→親自衝鋒」；
2 步兵+1 騎兵+1 蠻兵。

**Doctrine 最小詞彙**：觸發器×5 / 條件×4 / 動作×8 / 指令槽=4。

**資源**：情報點 10（買敵情）+ CP 3（手操 8 秒/點）。
**士氣**：全軍共 100；潰滅-15/主角被圍-10/奪渡口+10；<30 部隊無視 doctrine。

**引擎映射**：EventBus→doctrine 觸發器；Physics→squad 移動+地形互動；
TimeManager timeScale→階段切換；Serialization→永久死亡名冊；
Input+Camera→CP 手操。新建集中：doctrine 直譯器、squad AI、戰鬥 UI。

**驗證假設**：排卡→看執行→修卡循環是否好玩 / 4 卡槽是深度還是挫折 /
敵將習慣是否可觀測可利用 / CP 救火能否解 RPG 玩家微操癮。

**故意不做**：大地圖、多將內鬥、連鎖時間軸、敵方學習、沙盤模擬器、數值成長（二期彈藥）。

## Themes and Patterns

- **不確定性即玩法**：機率雲情報、敵將隱藏腳本、士氣執行變數——三層不確定性疊加
- **失敗生產力**：斷後回合、回放修卡、繳獲 doctrine、敵方學習——敗仗全部產出戰力或資訊
- **敵我同構**：敵將用同一套 doctrine 語法——可讀、可破譯、可繳獲、可學習
- **人性夾層**：腳本是意圖、部隊有性格、士氣會崩——完美計畫 vs 執行落差的戲劇性
- **書寫即戰鬥**：玩家的主動詞是「寫」不是「打」——寫得好的人贏

## Promising Combinations

- **情報雲 + 部署反轉**：雙方只看對方機率雲 → 偵查競賽成核心博弈
- **繳獲 + 敵方學習**：敵軍也繳獲你的 doctrine → 常用戰術被學走、必須換招
- **斷後回合 + 三拍情緒**：潰敗彈回正是「哀悼」拍的機制化
- **錄製轉譯 + 詞彙綁兵種**：手操錄影自動產出該兵種語法的卡草稿
- **人格三軸 + 挑撥卡 + 名將履歷**：敵方將領團是可拆解、可離間、可養成的對手生態

**[World #25]**: 旗語將軍（A類-不在場）
_Core Loop_: 帥旗台用旗語/號角/傳令兵下令；doctrine=戰前約定的旗語組合。
_Novelty_: 戰場噪音與旗手陣亡 = 指令失真；士氣執行變數的自然外衣。**史實向**。

**[World #26]**: 亡靈軍團書寫者（A類-不在場）
_Core Loop_: 死靈法師把指令符文刻進無意志屍卒的骨骸。
_Novelty_: 最純粹 doctrine 體驗；「老骨頭的名字是你刻的」讓永久死亡更痛。**神話向**。

**[World #27]**: 魔像工程師（A類-不在場）
_Core Loop_: 工坊編排「發條卡匣」插入魔像軍團；繳獲=拆敵魔像卡匣。
_Novelty_: doctrine 完全物理化（卡匣=槽位=實體資產）；ludonarrative 咬合最滿。**神話/蒸汽向**。

**[World #28]**: 敗軍之將的復盤（B類-身分限制）
_Core Loop_: 被收走兵符的貶將，只能「建議」有自己判斷的老部下打游擊。
_Novelty_: 士氣=老部下信任度；「自作主張」有最強敘事理由；戰敗線接主線。**史實向**。

**[World #29]**: 軍神代言人（B類-身分限制）
_Core Loop_: 戰神附身能見戰場「因果線」，動手就被神格抽離，只能預言式下令。
_Novelty_: 機率雲=神視未來殘影；凝滯點=神恩暫停（CP=燒神恩）。**神話向**。

**[World #30]**: 傀儡師（B類-身分限制）
_Core Loop_: RPG 隊伍在敵後行動，同時隔空操控戰場傀儡軍；兩線劇情交織。
_Novelty_: CP 手操=分神附體；城內行為影響戰場（燒糧→敵開局士氣-20）。**雙線敘事**。

**[World #31]**: 諸神棋局（C類-高概念）
_Core Loop_: 你是新晉「兵勢之神」，人間戰爭是你與老牌神明的對弈。
_Novelty_: 敵將人格三軸=神格牌風；繳獲 doctrine=窺見神的思路；格局最大。**神話向**。

**[World #32]**: 迴響戰場（C類-高概念）
_Core Loop_: 被詛咒的古代戰場每日重演；你是「改寫者」，用軍令改結局、撈回死者為部屬。
_Novelty_: 永久死亡名冊=從歷史撈回的人；回放=世界本身機制；敘事機制咬死。**神話+史實混合**。

**世界觀決策記錄**：全 8 案採納（potat：有史實與傳奇神話問題）。
潛在架構：doctrine 機制技術無關（旗語→信鴿→電報→神諭→數據鏈同機制換皮），
可成為「多時代章節」或「正史/神話雙層敘事」的底層 —— 
史實章節用 A/B 類世界，神話章節用 B/C 類世界，共享同一套戰鬥核心。

**[Failure #33]**: 失敗階梯
_Core Loop_: 失敗分 L0完美~L5全滅六級；L1~L4 繼續遊戲並產出不同後續內容（復仇事件/追擊戰/斷後回合）。
_Novelty_: 失敗是分岔不是終點；SL 規避的反制 =「讀檔反而吃虧」（失敗線有獨佔內容）。

**[Failure #34]**: 名冊即資產負債表
_Core Loop_: 永久死亡名單量化展示累積投資（練度/裝備/自寫卡）；遺物回收是獨立決策。
_Novelty_: 死亡情感重量 = 投資的可視化清算。

**[Failure #35]**: 收屍決策
_Core Loop_: 戰後遺體/裝備留在場上：立即收（冒回馬槍）/ 放棄（永久損失）/ 標記待回收（佔行動點）。
_Novelty_: 「為死人冒險」機制化；狡詐敵將會故意在屍體旁設伏。

**[Failure #36]**: 士氣債螺旋與破產保護
_Core Loop_: 連敗→士氣低→執行率降→更易敗；破產保護 = 強制休整回合（犒賞/軍營事件/處置逃兵黑暗選項）。
_Novelty_: 休整期是 RPG 內容而非罰站；「重整旗鼓」本身是 gameplay。

**[Failure #37]**: 敵方撿裝備
_Core Loop_: 丟在戰場的裝備/輜重/未回收 doctrine 卡被敵軍真實拾取——下場看到敵兵穿老周的甲、敵將用你的卡。
_Novelty_: 焦土決策（撤退前毀帶不走的）；你的失敗真的武裝敵人。

**[Failure #38]**: 名冊共鳴
_Core Loop_: 陣亡者的摯友/徒弟/同鄉在軍中有連鎖反應（復仇狂化/繼承部分經驗/士氣波動）。
_Novelty_: 死亡在人際網擴散——軍隊是關係圖，死一個節點震動整網。

**[Failure #39]**: 英靈殿/追憶
_Core Loop_: 陣亡名單是可拜訪場所：戰歷、陣亡「最後十秒」回放、遺言。
_Novelty_: 「哀悼」有實體場所；最後十秒 = 敵將當時用的卡 → 繳獲入口。

**[Numeric #40]**: 槽位債
_Core Loop_: 可超載塞卡 → 全軍 doctrine 執行延遲 +0.5s。
_Novelty_: 「多帶一張但全變慢」的自虐選項——給最優化癖的陷阱糖果。

**[Numeric #41]**: CP 機會成本化
_Core Loop_: CP 雙用途——手操救火 or 緊急全軍指令（保底按鈕但不免費）。
_Novelty_: 同一份 CP 在「微操」與「止損」間二選一；回答「要不要免費急停」= 有但要花 CP。

**[Numeric #42]**: 士氣雙向性
_Core Loop_: 士氣 <30 執行率 70%、<10 時 40%；超額士氣（>100）解鎖「勇氣執行」（後撤卡變交替掩護撤退）。
_Novelty_: 高士氣讓同卡打出上位效果——養士氣是隱性成長線。

**[Numeric #43]**: 情報貶值
_Core Loop_: 對同一敵將重複買同類情報漲價（他會故意改習慣）。
_Novelty_: 情報非一次性解鎖——敵將反偵查動態化。

**[Numeric #44]**: 時長即壓力
_Core Loop_: 戰鬥超 4 分鐘雙方每 10 秒 -2 士氣。
_Novelty_: 防龜機制內建士氣系統——戰鬥自然收斂不需額外計時器。

**[World #45]**: 正史與異聞錄
_Core Loop_: 每場歷史戰役有正史結局（得史實獎勵/史官記載）與異聞結局（解鎖神話線/if 劇情）。
_Novelty_: 「還原歷史」與「改寫歷史」兩種通關——天然二周目結構。

**[World #46]**: 兵書即卡組
_Core Loop_: 孫子兵法等真實兵書 = doctrine 模板卡組（「圍師必闕」= 現成包圍卡）。
_Novelty_: 中國兵書天然是 doctrine 語言——「可玩的兵書」是文化層面的獨特定位。

**[World #47]**: 史官視角結算
_Core Loop_: 戰後結算用史官筆法自動生成（「秋七月，將軍以寡擊眾於斷橋，槍兵隊長周氏戰歿」）。
_Novelty_: 玩家名冊 = 一部自己寫出來的史書；死亡名單有史筆重量。

## 世界觀架構決策：史實×神話雙層

**三候選架構**：
- **A 章節輪替**：神話層決策改寫史實層初始條件（神話是史實的編輯器）
- **B 雙層疊圖**：同一戰場史實層+神話層雙視角；兩套 doctrine 詞彙，同卡雙層效果
- **C 英雄史詩**：每章一位歷史名將戰役，doctrine 重現名戰術（4 卡槽寫出「破釜沉舟」？）

**混搭建議**：C 做骨架（名將傳記集）、B 做章內機制（雙層視角）、A 做幕間（神話改寫下一章史實條件）。

**失敗設計 × 三拍情緒**：失敗不是打斷循環，是循環的第三拍
（掌控=寫 doctrine 的自負 → 懸疑=眼看失敗燒 CP 救火 → 哀悼=名冊結算/收屍/休整再出發）。

**數值提案（斷橋原型）**：卡槽 4→終盤 7+王牌槽；CP 3 點（8 秒/點，成長給品質不給次數）；
士氣每小隊獨立+全軍均值（<30 執行 70%）；情報點物價表（人格檔案 3/習慣 4/部署 2/詞彙表 6）；
戰鬥目標 90s~4min，超時雙方士氣衰減。
**解鎖節拍**：每章只給一個語法維度（單條件→條件詞→修飾詞→連鎖→跨隊→王牌槽）。

## Party Mode 品質評估（已採納）

**總評**：方向獨特（「寫作戰鬥」定位市場罕見）、機制咬合、情緒引擎原創。

**三大風險**：
1. 受眾重疊度存疑 —— 寫腳本玩家 ∩ RTS/RPG 玩家比想像小；
   原型第一驗收標準：**完全不碰邏輯思維的 RPG 玩家能否 10 分鐘內排出一場能打的戰鬥**
2. 敵我同構的隱藏成本 —— 敵將 doctrine 應**手寫**（每個名將=精雕的謎題），
   人格向量只做微調，不要程序生成
3. 反饋延遲 —— 寫卡→看結果循環太長會殺死迭代樂趣；
   沙盤模擬器必須存在且要秒級，即時層建議 4x 加速

**兩個落地要點**：
- 回放走**事件錄製**而非模擬回放（引擎浮點物理不具決定性）
- 名冊分層：雜兵不進名冊，只有小隊長級以上——防死亡通貨膨脹

**範圍分層**：MVP（斷橋）→ 垂直切片（一章名將傳記+雙層視角）→ 完整版。
目前點子庫約 60% 屬於完整版，留作彈藥庫，勿滲進原型。

## 斷橋原型 → PotatoEngine 任務清單

**層級 0（骨架）**
- T-1 `BattleManager` 三階段狀態機（Deploy/Combat/Aftermath），配 TimeManager timeScale
- T-2 Doctrine 直譯器：`DoctrineCard{trigger,condition,action,modifier}`，
  觸發器走 EventBus 訂閱（非每幀輪詢）
- T-3 `SquadComponent` + 最小 AI：order queue，隊形偏移 + 分離力，不做個體尋路

**層級 1（內容）**
- T-4 斷橋地圖 JSON（區域/渡口/部署區/圖釘點/互動物件）
- T-5 敵將手寫腳本：格洛克 4 卡 + 人格三軸（侵略90/紀律40/狡詐10）

**層級 2（系統）**
- T-6 BattleResources：情報/CP/每隊士氣（<30 → 執行率 70%）
- T-7 BattleRecorder：EventBus 事件錄製 → JSON 回放（不重跑模擬，避開浮點非決定性）
- T-8 Roster：具名單位名冊 + 遺物，陣亡寫入 JSON（隊長級以上才入冊）

**層級 3（表現，ImGui debug 版先行）**
- T-9 回合層：卡槽欄+卡編輯器+地圖圖釘（內建新手套牌模板）
- T-10 即時層：狀態條/士氣條/CP 鈕/訊息流
- T-11 戰後：史官筆戰報+名冊+回放時間軸
- T-12 單位先用膠囊體/色塊

**順序**：T-1→T-3 骨架 → T-4/T-5 內容 → T-6~T-8 系統 → T-9~T-12 表現。
里程碑：T-1~T-8 = 無圖形 console 版斷橋可跑。

## 教學關設計（Tutorial — 不教語法，教「後悔」）

- **T-A 預設牌組先讓你贏一半**：4 槽預填 2 卡，敵將繞側翼無卡應對→小崩潰→
  史官暫停+回放高亮→玩家自己補第一張卡。第一次寫卡是為了補救失敗。
- **T-B 詞彙用兵種教不用語法教**：觸發/條件/動作三層隱形化，
  玩家以為在選兵種技能其實在組 doctrine。
- **T-C 錄製模式當輪椅**：手操一場→系統轉譯成卡草稿（品質故意低於手寫，
  只記單觸發器沒條件修飾→後期還是要學語法）。
- **T-D 敵情用看不用讀**：戰前 15 秒敵營剪影演出→玩家親眼看到部署→
  點「我看到了什麼」產生情報卡。
- **T-E 死亡名冊首啟用要痛**：劇情殺——掩護撤退的隊長「老周」必死，
  演出上讓 CP 手操也來不及（「你救不了」而非「系統不讓」），
  一個事件教名冊存在/死亡重量/收屍決策三件事。

教學節拍：關1 補卡(卡是補洞的) → 關2 錄製(操作=腳本原料) →
關3 剪影(偵查→針對配置) → 關4 自由斷橋(完整三拍)。
每關只教一件事且綁一個情緒事件——玩家記住的不是規則是那次後悔。

## 敵方經濟（敵將也是有資源限制的指揮官）

敵方資源三件套：兵力值 / 糧草(歸零→士氣衰減+執行率-30%) / 軍令點(敵將的 CP)。

- **EC-1 經濟可視化**：資源=地圖上可攻擊的實體資產（糧車/驛站/傳令兵路線），
  不做進度條。
- **EC-2 軍令點=敵將體力**：超出腳本的即興反應燒軍令點，燒完→退回純腳本模式
  變可完全預測。騷擾流戰術=消耗敵將意志力（讓他變笨）。
- **EC-3 斷補給線 doctrine**：玩家詞彙含「襲補給線/燒糧車/截傳令兵」；
  傳令被截→敵小隊卡在舊指令重複執行——打敵方 doctrine 系統的實體 API。
- **EC-4 敵方也省著打**：缺糧敵將切「節糧腳本」（收縮/速戰）；
  資源狀態是人格的調變器——滿糧莽夫壓上，缺糧莽夫梭哈。
- **EC-5 戰場經濟互餵**：遺留輜重/屍體裝備真被敵撿→加進他的兵力糧草（接 F-5）；
  潰敗丟輜重=資敵。
- **EC-6 敵方經濟履歷**：跨戰役累積——連續燒糧→敵後續場次開局糧草-40%+
  敵將學會「護糧隊」卡。場場燒糧也是一條勝利路線。

對稱性約束：玩家有同構經濟（補給線會被襲、CP 有戰役級疲勞版）；
你能打的經濟戰敵將也能打你——護補給線也是 doctrine 合法用途。
UI 只做資產圖示不做資源條；「傳令被截」要顯眼提示讓失敗有歸因。

## 音樂音效（聽得見的 doctrine）

- **M-1 doctrine 即樂譜**：每張卡觸發有專屬音型（槍陣=鼓陣/齊射=弦樂上行/
  突擊=號角）；配樂由當下觸發的卡即興組成——兩場打法聽起來是不同曲子。
  配樂=戰況可聽化回放，聽得出腳本在跑。卡→音檔映射表接 EventBus→AudioSystem。
- **M-2 敵將人格=配樂主題**：每將音樂簽名（格洛克=戰鼓+喉音），
  聽得出敵將是誰、聽得出他換套路。
- **M-3 士氣可聽**：高士氣=整齊踏步盾擊戰吼；崩潰=零散腳步丟盔有人喊名字逃命；
  執行率下降「聽得出來」。
- **M-4 史官筆結算音**：戰報逐字敲出——毛筆聲竹簡聲，每個名字落筆一聲悶鐘。
- **M-5 凝滯點聲音設計**：CP 手操 8 秒世界全低通變悶只剩自己呼吸兵器聲，
  時間到聲音灌回來——靈魂出竅體感。
- **M-6 聲音情報層**：視野外動向用聲音呈現（鳥驚飛=伏兵移動/悶蹄=騎兵集結/
  號角方位=敵令下達位置）——空間音訊是偵查系統一部分；
  靜音玩家需視覺對應提示（公平性）。

地雷：音型混濁→同時只播最高優先 2-3 motif；分層 stems 非完整曲子；
原型期 5-6 個 motif 驗證「聽得出腳本」。
