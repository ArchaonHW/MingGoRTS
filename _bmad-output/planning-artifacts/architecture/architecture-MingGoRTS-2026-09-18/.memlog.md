- (decision) paradigm=pipes-and-filters: 影音生成管線分四段(source→capture→encode/dataset→train/consume), 段間只靠 output/ 下的 potato.* manifest 工件通訊, 不跨 GPU 邊界共享記憶體 API
- (decision) GPU 段一律是 CLI executable 不是 library: 需要 GL context 的程式碼只存在 add_executable target 內([SKIP] exit-0 慣例), orchestration/consumer 端不連結 glad/glfw——無獨顯機可全量建置+測試 CPU 段
- (decision) 新目錄 Media/: HeadlessCapture(hidden ctx+FBO+flip+PNG, 現 4x 複製貼上), VideoEncoder(ffmpeg pipe 單點封裝), DatasetManifest(potato.*_dataset/1 讀寫), PipelineRunner(段編排 stub)
- (decision) dataset manifest 是跨機器 wire format: 統一 potato.<kind>_dataset/1 schema; GPU 機產資料, 文書機開發 consumer——manifest 即介面
- (decision) ffmpeg 維持外部行程契約: _popen rawvideo stdin pipe; 引擎永不連結編碼器; CLI 參數集中在 VideoEncoder 單檔
- (decision) 訓練/推論維持 in-tree CPU MLP(AI::NeuralNetwork + Rendering::NeuralGraphics); .pnn 是模型交換格式; 外部 DL 框架(GPU 訓練)為 out-of-tree consumer, 引擎不綁定
- (assumption) 使用者不打算引入 PyTorch/ONNX 等外部 DL 框架——保持 in-tree MLP + manifest 契約
- (decision) VideoDataDemo PNG 未翻轉(vs top-down bbox)記為既有 defect——HeadlessCapture 統一 top-down 輸出時一併修正; output/video_ds/ 補進 .gitignore
