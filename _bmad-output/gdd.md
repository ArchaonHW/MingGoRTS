# 民國史詩 - Game Design Document

**Author:** Potato
**Game Type:** Strategy (策略遊戲)
**Target Platform(s):** PC (Windows) → Mobile (Android/iOS) → Console

---

## Executive Summary

### Game Name

民國史詩

### Core Concept

民國史詩是一款**歷史決策後果體驗遊戲**，核心是讓玩家在真實的民國歷史情境中做出策略決策，並親身體驗這些決策帶來的歷史後果。遊戲巧妙融合了四大經典策略遊戲（全軍破敵、騎馬與砍殺2、鋼鐵雄心、Elin）的精髓，創造出獨一無二的**民國時期大戰略體驗**。

### Game Type

**Type:** Strategy (策略遊戲)
**Framework:** 此 GDD 使用 strategy 模板，包含資源系統、單位設計、科技進程、地圖地形、AI 對手和勝利條件等專用章節

### Unique Selling Points (USPs)

**🎯 第一原理核心：**
- **決策真實性**：每個遊戲決策都基於歷史真實選擇
- **後果體驗**：玩家直接感受決策的歷史重量
- **人性理解**：通過遊戲理解歷史中的人性掙扎
- **時代還原**：還原民國時代的真實複雜性

**🏗️ 設計哲學：**
- **簡化但深刻**：去除不必要的複雜，保留核心的歷史體驗
- **技術為體驗**：所有技術選擇都服務於歷史還原
- **規模有意義**：大規模是為了還原歷史的真實感
- **教育娛樂並重**：在娛樂中自然傳達歷史理解

**💡 獨特價值：**
- **填補市場空白**：提供稀缺的民國題材高品質遊戲
- **歷史教育創新**：通過遊戲進行歷史普及
- **文化傳承意義**：用現代技術保存和傳播歷史文化

### Multi-Layer Strategy System

**🗺️ 戰略地圖層面 (鋼鐵雄心風格)：**
- 管理整個勢力的經濟、工業和外交
- 深度科技樹研發系統
- 動態的歷史事件和決策系統

**⚔️ 戰役戰術層面 (全軍破敵風格)：**
- 大規模戰役地圖的即時戰鬥
- 複雜的地形和戰術考量
- 多兵種協同作戰系統

**🎯 個人角色層面 (騎馬與砍殺風格)：**
- 玩家作為指揮官的個人成長
- 可以親身參與戰鬥
- 動態的NPC互動和招募系統

**🏗️ 基地建設層面 (Elin風格)：**
- 豐富的建造和升級系統
- 獨特的生存和資源管理
- 個性化的基地發展路線

### Cross-Platform Technology

**技術特色：**
- **跨平台適配**：PC端享受完整戰略深度，移動端優化操作體驗
- **AI輔助創作**：使用Stable Diffusion生成符合民國風格的美術資產
- **大規模作戰**：UE5 Nanite技術支援100+單位同時戰鬥

### Progressive Development Strategy

**🎯 漸進式複雜度：**
- **Sprint 1**：RTS核心迴圈（單位控制、基礎資源）
- **Sprint 2**：基地建設與經濟系統
- **Sprint 3**：戰役地圖與戰術戰鬥
- **Sprint 4**：個人角色與外交系統
- **Sprint 5+**：完整的大戰略層次

### Cross-Era DLC Expansion Strategy

**🏛️ 核心時代：民國時期 (1912-1949)**
- **歷史豐富度**：軍閥割據、抗日戰爭、國共內戰
- **技術變革**：冷兵器到現代化武器的過渡期
- **文化衝突**：傳統與現代、東方與西方的交匯

**🕰️ 歷史回溯DLC路線：**
- **DLC 1**：晚清時期 (1840-1911) - 鴉片戰爭、洋務運動
- **DLC 2**：明清時期 (1368-1840) - 朝代更替、滿漢融合
- **DLC 3**：唐宋時期 (618-1279) - 文化鼎盛、海上絲路

**🚀 未來延伸DLC路線：**
- **DLC 4**：現代時期 (1950-2000) - 冷戰對峙、經濟改革
- **DLC 5**：近未來 (2000-2100) - 資源爭奪、太空探索

**⚔️ 奇幻跨界DLC路線：**
- **DLC 6**：魔戒世界 - 軍閥變成精靈/矮人領主
- **DLC 7**：戰鎚世界 - 現代化部隊 vs 異魔獸人軍團
