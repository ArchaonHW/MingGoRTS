# RTS核心功能開發

## 目標
- 基於MingCore事件系統開發RTS核心功能
- 實現單位控制、攝影機、戰鬥系統
- 建立可擴展的RTS架構

## 核心功能模組
1. **單位管理系統**
   - 單位創建和銷毀
   - 單位移動和路徑規劃
   - 單位選擇和控制

2. **攝影機系統**
   - RTS風格攝影機
   - 視角控制和縮放
   - 地圖導航

3. **戰鬥系統**
   - 傷害計算
   - 戰鬥狀態管理
   - 技能系統

4. **資源管理**
   - 資源收集和存儲
   - 資源消耗系統
   - 經濟平衡

## 實現計劃
1. 基於事件系統設計架構
2. 創建核心RTS組件
3. 實現單位控制邏輯
4. 開發攝影機系統
5. 集成戰鬥和資源系統

## 技術要求
- 使用MingCore事件總線
- 模組化設計
- 可擴展架構
- 性能優化
