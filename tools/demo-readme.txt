MingGoRTS — 斷橋攻防戰（垂直切片 demo）
========================================

雙擊 DuanqiaoPlayable.exe 開始。

流程：標題頁 → 開戰 → 規劃（編教條卡）→ 執行（看教條自己打）→ 戰後結算
→ 返回主選單可再戰。

操作
----
規劃：左欄選隊，中欄排教條卡（觸發→動作），Alt+拖移目標/集結圖釘，
      「開戰」進入執行。
執行：左鍵選隊，右鍵下令（耗 CP）；敵軍是機率雲——
      點雲=探測（1 情報，雲收縮），Shift+點雲=觀測（2 情報，塌縮現形），
      走近 3 格內免費揭露。
      Space 暫停，WASD 平移視角，滾輪升降，Esc 取消選取，1/2/3 倍速。
設定：標題頁可切主題（現代軍事/泥濘沙盤）與介面縮放。

說明
----
- 字體為打包的 Noto Sans/Serif TC（SIL OFL），不依賴系統字體。
- 教學版另有獨立程式（不在此包內）。
- 本包為玩法驗證切片：音效、小地圖、完整設定將在後續里程碑加入。
