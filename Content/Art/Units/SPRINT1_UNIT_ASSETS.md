# Sprint 1 單位素材規劃

## 基礎單位類型

### 1. 測試單位 (Test Unit)
**用途:** Sprint 1 開發測試
**風格:** 簡單幾何形狀，易於識別
**要求:** 低多邊形，快速渲染

### 2. 單位素材需求

#### 2.1 基礎步兵單位
```
單位ID: INFANTRY_BASIC
模型類型: 低多邊形人形
多邊形數量: < 200
紋理解析度: 256x256
動畫: 待機、行走、選擇
```

#### 2.2 基礎載具單位
```
單位ID: VEHICLE_BASIC
模型類型: 簡單盒狀載具
多邊形數量: < 150
紋理解析度: 256x256
動畫: 待機、移動、選擇
```

### 3. 單位狀態指示器

#### 3.1 選擇狀態
- **未選擇:** 正常顯示
- **已選擇:** 綠色高亮邊框
- **懸停:** 淡藍色高亮

#### 3.2 狀態指示
- **待機:** 正常顏色
- **移動中:** 黃色狀態指示器
- **攻擊中:** 紅色狀態指示器
- **受傷:** 閃爍效果

### 4. 材質規格

#### 4.1 基礎材質
```
材質名稱: M_Unit_Basic
類型: Unlit Material
顏色: 可自定義參數
紋理: 漫反射紋理
```

#### 4.2 選擇材質
```
材質名稱: M_Unit_Selected
類型: Transparent Material
顏色: 綠色發光
透明度: 可調節
```

### 5. 動畫規格

#### 5.1 動畫狀態
- **Idle:** 待機動畫 (1-2秒循環)
- **Walk:** 行走動畫 (0.5秒循環)
- **Select:** 選擇動畫 (0.3秒)
- **Attack:** 攻擊動畫 (0.8秒)

#### 5.2 動畫要求
- 骨骼數量: < 20
- 動畫幀率: 30 FPS
- 動畫長度: < 3秒
- 過渡動畫: 平滑切換

### 6. 性能要求

#### 6.1 渲染性能
- 單一單位渲染時間: < 1ms
- 100個單位總渲染時間: < 50ms
- GPU記憶體使用: < 100MB per 100 units
- CPU影響: 最小化

#### 6.2 內存優化
- 單位數據大小: < 10KB
- 動畫數據大小: < 5KB
- 紋理大小: < 50KB per unit
- 總內存使用: < 2GB for 1000 units

### 7. 臨時素材方案

#### 7.1 UE5基礎形狀
- 使用UE5內置的幾何形狀
- 立方體作為臨時單位
- 球體作為臨時建築
- 平面作為臨時地形

#### 7.2 程序化生成
- 使用材質實例生成變化
- 程序化顏色變化
- 簡單噪聲紋理生成
- 基礎形狀組合

### 8. 素材清單

#### 8.1 必需素材
- [ ] 基礎步兵模型 (FBX)
- [ ] 基礎載具模型 (FBX)

#### 9.1 建模工具
- Blender (免費)
- 3ds Max (專業)
- Maya (專業)

#### 9.2 紋理工具
- Photoshop (專業)
- GIMP (免費)
- Substance Painter (專業)

#### 9.3 動畫工具
- Blender (免費)
- 3ds Max (專業)
- Mixamo (在線動畫)

### 10. 導出設置

#### 10.1 FBX導出設置
```
坐標系統: Z-Up
單位: 厘米
骨骼: 启用
動畫: 启用
材質: 嵌入
```

#### 10.2 紋理導出設置
```
格式: PNG
顏色深度: 8-bit
壓縮: 無損失
Mipmap: 生成
```
