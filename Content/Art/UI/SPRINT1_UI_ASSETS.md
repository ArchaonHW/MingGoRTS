# Sprint 1 UI素材規劃

## 基礎UI系統

### 1. UI系統架構

#### 1.1 UI層級結構
```
UI層級:
├── HUD (主界面)
│   ├── 資源顯示
│   ├── 單位信息
│   └── 小地圖
├── 單位選擇UI
│   ├── 選擇框
│   ├── 健康條
│   └── 狀態圖標
└── 交互提示
    ├── 移動標記
    ├── 攻擊標記
    └── 錯誤提示
```

#### 1.2 UI材質需求
- **透明度:** 支持半透明效果
- **縮放:** 支持不同解析度
- **顏色:** 可配置主題色
- **動畫:** 簡單過渡動畫

### 2. 核心UI元素

#### 2.1 資源顯示
```
元素類型: 資源圖標 + 數值
顯示位置: 屏幕左上角
圖標尺寸: 32x32 像素
字體大小: 16pt
背景樣式: 半透明背景
```

#### 2.2 單位選擇框
```
元素類型: 選擇框 + 高亮
顯示位置: 圍繞選中單位
框線樣式: 實線，2像素寬
框線顏色: 綠色 (可配置)
高亮效果: 邊緣發光
```

#### 2.3 單位信息面板
```
元素類型: 信息面板 + 圖標
顯示位置: 屏幕左下角
面板尺寸: 200x150 像素
背景樣式: 半透明黑色背景
信息內容: 單位類型、生命值、狀態
```

#### 2.4 小地圖
```
元素類型: 縮略地圖 + 單位標記
顯示位置: 屏幕右下角
地圖尺寸: 150x150 像素
標記類型: 單位、建築、資源
縮放級別: 2x - 8x 可調
```

### 4. UI動畫系統

#### 4.1 過渡動畫
```
淡入效果: 0.3秒
淡出效果: 0.3秒
滑動效果: 0.5秒
縮放效果: 0.2秒
```

#### 4.2 狀態動畫
```
閃爍效果: 錯誤提示
脈動效果: 選中狀態
搖晃效果: 受傷狀態
旋轉效果: 載入狀態
```

### 5. UI字體設置

#### 5.1 字體選擇
```
主字體: Arial (系統字體)
數字字體: Consolas (等寬字體)
中文支持: 微軟正黑體
備用字體: Sans-serif
```

#### 5.2 字體樣式
```
標題字體: 18pt, 粗體
正文字體: 14pt, 常規
數字字體: 16pt, 等寬
提示字體: 12pt, 斜體
```

### 6. UI顏色主題

#### 6.1 主題色配置
```
主色調: #2E7D32 (綠色)
次要色: #4CAF50 (淺綠色)
警告色: #FF9800 (橙色)
錯誤色: #F44336 (紅色)
背景色: #1A1A1A (深灰)
文字色: #FFFFFF (白色)
```

#### 6.2 可訪問性
```
高對比度: 黑白模式
色盲友好: 圖標+文字
字體縮放: 支持1x-2x
鍵盤導航: 支持Tab鍵
```

### 7. UI性能優化

#### 7.1 渲染優化
```
UI層級: 分層渲染
批處理: 合併繪製調用
紋理圖集: 減少狀態切換
字體緩存: 預渲染字體
```

#### 7.2 內存優化
```
UI紋理: < 50MB
UI字體: < 10MB
UI動畫: < 5MB
總UI內存: < 100MB
```
