# 馬鈴薯Logo設計指南

## Logo設計理念

### 核心概念
**馬鈴薯 + 革新精神 = 工作室標識**

設計目標:
- 傳達民國歷史背景
- 體現遊戲開發創新
- 保持馬鈴薯個人特色
- 適合RTS遊戲風格

---

## 視覺元素設計

### 主體元素
```
1. 馬鈴薯圖形 (簡化現代風格)
   - 形狀: 抽象馬鈴薯輪廓
   - 風格: 幾何簡化 + 有機結合
   - 顏色: 主色調 + 漸變效果

2. 革新符號
   - 形狀: 閃電/星星/光芒
   - 位置: 馬鈴薯右上角
   - 效果: 動態閃爍

3. 中國傳統元素
   - 紋理: 雲紋/龍紋/回紋
   - 邊框: 傳統邊飾
   - 色彩: 古典配色

4. 工作室名稱
   - 字體: 現代中文 + 英文
   - 排版: 橫向/縱向組合
   - 風格: 簡潔有力
```

## Logo變體設計

### 主要Logo (彩色版)
```
使用場景: 開頭動畫、網站、宣傳
技術要求:
- 格式: SVG (矢量) + PNG (位圖)
- 解析度: 1024x1024 (SVG可縮放)
- 顏色: 全彩色 + 單色版
- 背景: 透明背景
```

### 標準Logo (單色版)
```
使用場景: 小尺寸應用、水印
技術要求:
- 格式: SVG + PNG
- 解析度: 512x512, 256x256, 128x128
- 顏色: 純白色 + 純黑色版
- 背景: 透明背景
```

### 圖標Logo (簡化版)
```
使用場景: 網站圖標、手機圖標
技術要求:
- 格式: SVG + PNG + ICO
- 解析度: 64x64, 32x32, 16x16
- 顏色: 單色版
- 背景: 透明背景
```

### 中文部分
```
字體選擇:

- 副標題: 思源黑體 (現代簡潔)
```

### 英文部分
```
字體選擇:
- 主要名稱: Montserrat Bold
- 副標題: Montserrat Regular
- 標語: Montserrat Light

排版規則:
- 大小比例: 中文:英文 = 2:1
- 間距調整: 字母間距適度增加
- 風格統一: 保持現代簡潔
```

## 動畫版本設計

### 靜態Logo
```
用途: 網站、文檔、名片
動畫: 無
格式: SVG + PNG
時長: 不適用
```

### 動態Logo
```
用途: 開頭動畫、載入畫面
動畫: 簡單動畫效果
格式: APNG + GIF + MP4
時長: 2-5秒循環
```

### 互動Logo
```
用途: 網站、應用程式
動畫: 懸停/點擊效果
格式: CSS動畫 + JavaScript
時長: 0.3-1秒交互
```

## 技術規格

### 矢量格式
```
文件格式: SVG
編碼: UTF-8
視窗: 定義完整視窗
路徑: 閉合路徑優先
文字: 轉換為路徑
```

### 位圖格式
```
文件格式: PNG (無損失)
壓縮: 無壓縮或最小壓縮
透明度: 8位Alpha通道
顏色: sRGB色彩空間
```

### 尺寸規格
```
超大尺寸: 2048x2048 (高質量)
大尺寸: 1024x1024 (標準應用)
中尺寸: 512x512 (小圖標)
小尺寸: 256x256 (工具欄)
微小尺寸: 128x128 (狀態欄)
```

## 應用指南

### 網站使用
```
標準用法: <svg> 標籤
響應式: 使用不同尺寸
背景適應: 深色/淺色模式
動畫: CSS hover效果
```

### 動畫使用
```
視頻格式: MP4 (H.264)
透明背景: 支持Alpha通道
循環播放: 無限循環
位置疊加: 視頻疊加層
```

### 應用程式使用
```
圖標格式: ICO + PNG
啟動畫面: 全屏顯示
載入動畫: 循環播放
狀態欄: 系統托盤圖標
```
