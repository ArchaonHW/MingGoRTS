# RTSUnit 測試場景

## 測試目標
驗證RTSUnit基類的基本功能：
- 單位創建和初始化
- 單位選擇和取消選擇
- 單位移動功能
- 事件發布和接收
- 狀態管理

## 測試步驟

### 1. 單位創建測試
- [ ] 在編輯器中創建TestUnit實例
- [ ] 驗證單位ID自動生成
- [ ] 檢查單位屬性初始化
- [ ] 確認組件正確設置

### 2. 選擇功能測試
- [ ] 點擊單位觸發選擇
- [ ] 驗證選擇高亮效果
- [ ] 檢查選擇事件發布
- [ ] 測試取消選擇功能

### 3. 移動功能測試
- [ ] 選中單位後右鍵移動
- [ ] 驗證移動到目標位置
- [ ] 檢查移動事件發布
- [ ] 測試狀態轉換

### 4. 事件系統測試
- [ ] 驗證單位創建事件
- [ ] 驗證選擇/取消選擇事件
- [ ] 驗證移動事件
- [ ] 驗證狀態變化事件

## 預期結果
- 單位可以正常創建和顯示
- 選擇功能正常工作
- 移動功能正常執行
- 事件系統正常發布和接收
- 狀態管理正確運行
