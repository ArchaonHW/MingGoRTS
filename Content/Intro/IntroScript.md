# MingGoRTS 開頭動畫腳本

## 動畫結構

### 第一幕：標題卡片 (3秒)
- **視覺**: 民國時期風格的紋理背景
- **文字**: "MingGoRTS" (中英文標題)
- **音效**: 民國時期音樂開頭
- **效果**: 淡入淡出

### 第二幕：歷史背景 (5秒)
- **視覺**: 民國歷史照片輪播
- **文字**: 
  - "1911年，辛亥革命成功"
  - "中華民國建立"
  - "軍閥混戰時期"
- **音效**: 歷史旁白音效
- **效果**: 圖片切換動畫

### 第三幕：遊戲標題 (4秒)
- **視覺**: 遊戲 Logo 和副標題
- **文字**: 
  - "民國歷史背景即時戰略遊戲"
  - "重現歷史，改變命運"
- **音效**: 史詩音樂
- **效果**: 閃光效果

## 文字內容

### 標題文字
```
MingGoRTS
民國歷史背景即時戰略遊戲
```

### 歷史背景文字
```
1911年，辛亥革命成功
中華民國建立
軍閥混戰時期
外敵入侵，國難當頭
英雄輩出，保家衛國
```

### 遊戲標語
```
重現歷史，改變命運
指揮軍隊，統一中國
```

## 音效設計

### 背景音樂
- **風格**: 民國時期軍樂
- **樂器**: 軍鼓、銅管樂器
- **節奏**: 雄壯、莊重

### 音效
- **轉場音效**: 歷史照片切換音
- **按鈕音效**: 傳統中國音效
- **環境音**: 戰場環境音

## 視覺設計

### 色彩方案
- **主色**: 中國紅 (#DE2910)
- **輔色**: 金色 (#FFD700)
- **背景**: 深褐色 (#3E2723)
- **文字**: 米白色 (#F5F5DC)

### 字體設計
- **標題**: 楷體/隸體
- **內文**: 宋體
- **英文**: Times New Roman

### 紋理風格
- **背景**: 民國時期舊照片紋理
- **邊框**: 中國傳統花紋
- **裝飾**: 雲紋、龍紋

## 技術規格

### 解析度
- **標準**: 1920x1080
- **支援**: 16:9, 4:3
- **適配**: 自動縮放

### 檔案格式
- **紋理**: .png (支援透明)
- **音效**: .wav/.ogg
- **影片**: .mp4 (可選)

### 效能要求
- **記憶體**: < 100MB
- **載入時間**: < 2秒
- **幀率**: 60 FPS
