## 🛠️ 具體操作指南

### 圖像生成操作

#### Midjourney 操作流程
1. **啟動 Discord**
   - 加入 Midjourney 伺服器
   - 進入 #newbies 頻道

2. **使用提示詞**
   ```
   /imagine [提示詞]
   ```

3. **參數設置**
   ```
   --ar 16:9 --q 2 --style raw --s 750
   ```

4. **下載圖片**
   - 點擊生成圖片
   - 選擇 "Open in Browser"
   - 右鍵保存圖片

#### DALL-E 3 操作流程
1. **使用 ChatGPT**
   - 開啟 ChatGPT Plus
   - 選擇 DALL-E 3

2. **輸入提示詞**
   - 直接輸入圖像提示詞
   - 添加風格描述

3. **調整和優化**
   - 根據結果調整提示詞
   - 多次生成選擇最佳

### 音效生成操作

#### Suno AI 操作流程
1. **訪問 Suno AI**
   - 開啟 Suno AI 網站
   - 註冊帳號

2. **創作音樂**
   - 選擇 "Custom Mode"
   - 輸入音樂提示詞

3. **調整參數**
   - 設置時長: 12秒
   - 選擇風格: Military/March

4. **下載音效**
   - 點擊下載按鈕
   - 選擇 WAV 格式

#### Udio 操作流程
1. **訪問 Udio**
   - 開啟 Udio 網站
   - 登入帳號

2. **生成音樂**
   - 輸入音樂描述
   - 設置參數

3. **優化音樂**
   - 調整樂器配置
   - 修改風格元素

## 🔧 常見問題解決

### 圖像生成問題

#### 問題 1: 歷史不準確
**解決方案**:
- 添加更具體的時代描述
- 包含準確的服飾和建築描述
- 使用負面提示詞排除現代元素

#### 問題 2: 風格不統一
**解決方案**:
- 統一使用相同的風格關鍵詞
- 保持一致的色彩方案
- 使用相同的技術參數

#### 問題 3: 文字出現
**解決方案**:
- 添加 "no text, no watermark" 負面提示詞
- 使用 "--no text" 參數
- 手動去除文字

### 音效生成問題

#### 問題 1: 時長不準確
**解決方案**:
- 明確指定所需時長
- 使用編輯工具裁剪
- 多次生成選擇最佳

#### 問題 2: 風格不符
**解決方案**:
- 詳細描述樂器配置
- 指定具體的音樂風格
- 參考歷史音樂範例
