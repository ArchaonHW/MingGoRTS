# Original commander portrait atlas

`commanders-v1.png` is an original image generated with the built-in OpenAI image generation tool on 2026-10-02 for this project, at the user's request for realistic military character art.

The file contains three equal square panels in one horizontal atlas: friendly commander, infantry officer, and opposing commander. `Examples/CharacterArt.h` selects panels with UV coordinates. Portraits are illustrated character presentation assets; they are not rendered 3D models or a claim to match the battlefield mesh exactly.

The prompt requested fictional East Asian officers, original uniforms, realistic painted anatomy and materials, and no real-person likenesses, franchise characters, flags, text, or existing insignia. The user's screenshot supplied the stylistic direction; no artwork was extracted from it. Keep this atlas in `assets/portraits/` when packaging the visual demo.
