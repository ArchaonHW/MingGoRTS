# 12勢力美術資源規劃

## 整體美術風格指導

### 主視覺風格：寫實歷史風格 + 中國傳統美學
- **色彩基調**: 以大地色系為主，配合各勢力專屬顏色
- **畫面風格**: UE5 Nanite + Lumen 實現電影級畫質
- **UI風格**: 民國時期報紙/文書風格，融入傳統紋樣
- **單位風格**: 基於歷史照片和文獻考證的寫實設計

## 技術規格

### 3D模型規格
- **高模**: 50,000-100,000 三角面
- **中模 (LOD1)**: 10,000-20,000 三角面
- **低模 (LOD2)**: 2,000-5,000 三角面
- **貼圖尺寸**: 2048x2048 (主要), 1024x1024 (次要)
- **格式**: FBX, 導入UE5 Nanite

### 材質規格
- **PBR工作流程**: Metallic/Roughness
- **紋理貼圖**: BaseColor, Normal, Metallic, Roughness, AO, Emissive
- **材質實例**: 每勢力創建母材質，使用實例變體

### 2D美術規格
- **UI元素**: PNG, 透明背景
- **分辨率**: 根據UI尺寸 (通常 512x512 或 1024x1024)
- **色彩空間**: sRGB
