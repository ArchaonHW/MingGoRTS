## 遊戲介紹

### 遊戲特色

MingGoRTS 是一款獨特的即時戰略遊戲，將明朝歷史與現代遊戲機制完美融合：

- **歷史準確性** - 基於真實的明朝歷史事件和人物
- **教育價值** - 在娛樂中學習歷史知識
- **戰略深度** - 複雜的單位、建築和經濟系統
- **沉浸式體驗** - 支持 VR 和 AR 技術
- **個人化學習** - AI 驅動的個人化教育內容
- **多人協作** - 與朋友一起體驗歷史

### 故事背景

遊戲設定在明朝（1368-1644），玩家將扮演明朝的統治者或將領，經歷從建國到衰亡的完整歷史進程。遊戲涵蓋了明朝的重要歷史事件，包括：

- 朱元璋建立明朝
- 永樂大典編纂
- 鄭和下西洋
- 土木堡之變
- 萬曆中興
- 明朝滅亡

## 快速開始

### 系統要求

#### 最低要求
- **操作系統**: Windows 10 64-bit
- **處理器**: Intel Core i5 或 AMD Ryzen 5
- **內存**: 16GB RAM
- **顯卡**: NVIDIA GTX 1060 或 AMD RX 580
- **存儲**: 50GB 可用空間

#### 推薦配置
- **操作系統**: Windows 11 64-bit
- **處理器**: Intel Core i7 或 AMD Ryzen 7
- **內存**: 32GB RAM
- **顯卡**: NVIDIA RTX 3070 或 AMD RX 6700 XT
- **存儲**: 100GB SSD

### 安裝和啟動

1. **下載遊戲** - 從官方網站或 Steam 下載
2. **安裝遊戲** - 運行安裝程序
3. **首次啟動** - 雙擊桌面圖標啟動遊戲
4. **創建帳號** - 選擇用戶名和設置個人資料
5. **完成教程** - 跟隨新手教程了解基本操作

### 基本控制

#### 鍵盤控制
- **W/A/S/D** - 移動攝像機
- **Q/E** - 旋轉攝像機
- **鼠標左鍵** - 選擇單位
- **鼠標右鍵** - 移動單位或攻擊
- **空格鍵** - 暫停遊戲
- **ESC** - 打開主菜單
- **Tab** - 切換界面模式
- **F1** - 打開幫助菜單

#### 鼠標控制
- **左鍵拖拽** - 框選多個單位
- **右鍵拖拽** - 移動單位到指定位置
- **滾輪** - 縮放視圖
- **中鍵** - 重置視圖角度

### 遊戲界面

遊戲中的主要界面元素：

#### 1. 資源欄（頂部）
- **金幣** 💰 - 經濟資源
- **糧食** 🌾 - 人口和軍隊維持
- **木材** 🪵 - 建築材料
- **石頭** 🪨 - 建築和防禦
- **鐵礦** ⛏️ - 武器和裝備

#### 2. 小地圖（右上角）
- 顯示整個戰場的縮覽圖
- 綠點表示友方單位
- 紅點表示敵方單位
- 黃點表示中立單位

#### 3. 單位信息面板（左下角）
- 顯示選中單位的詳細信息
- 包括生命值、攻擊力、防禦力等
- 可用的特殊技能

#### 4. 建築菜單（底部）
- 顯示可建造的建築類型
- 分為軍事、經濟、防禦等類別
- 顯示建築成本和需求

#### 5. 時間控制（底部中央）
- 暫停/繼續按鈕 ⏸️
- 遊戲速度控制（0.5x, 1x, 2x, 4x）
- 當前遊戲時間和日期顯示

## RTS 模式

### 單位系統

#### 單位類型
MingGoRTS 包含多種單位類型：

**軍事單位**
- **步兵** 🗡️ - 基礎近戰單位
- **弓箭手** 🏹 - 遠程攻擊單位
- **騎兵** 🐎 - 高機動性單位
- **將軍** ⚔️ - 強力指揮官單位
- **攻城器械** 🏰 - 攻城專用單位

**經濟單位**
- **農民** 👨‍🌾 - 資源收集單位
- **商人** 💼 - 貿易和經濟單位
- **學者** 📚 - 研究和知識單位
- **工匠** 🔨 - 建築和維修單位

#### 單位屬性
每個單位都有以下屬性：
- **生命值** ❤️ - 單位的生命點數
- **攻擊力** ⚔️ - 對敵人的傷害能力
- **防禦力** 🛡️ - 減少受到的傷害
- **移動速度** 🏃 - 單位的移動速度
- **視野範�** 👁️ - 單位的偵察範圍
- **攻擊範圍** 🎯 - 單位的攻擊距離
- **特殊技能** ✨ - 單位的獨特能力

### 建築系統

#### 建築類型

**軍事建築**
- **兵營** 🏕 - 訓練軍事單位
- **馬廄** 🐎 - 訓練騎兵單位
- **射箭場** 🏹 - 訓練遠程單位
- **軍械庫** ⚔️ - 生產武器和裝備

**經濟建築**
- **農場** 🌾 - 生產糧食
- **伐木場** 🪵 - 生產木材
- **採石場** 🪨 - 生產石頭
- **冶鐵廠** ⛏️ - 生產鐵礦
- **市場** 💰 - 進行貿易

**防禦建築**
- **城牆** 🧱 - 防禦敵人攻擊
- **箭塔** 🏹 - 遠程防禦
- **城門** 🚪 - 控制城鎮出入
- **護城河** 💧 - 額外防禦

**特殊建築**
- **學府** 📚 - 研究新技術
- **宮殿** 👑 - 政治中心
- **寺廟** 🏛️ - 宗教和文化中心
- **醫館** 🏥 - 治療傷兵

### 經濟系統

#### 資源管理
- **資源收集** - 農民自動收集資源
- **資源存儲** - 倉庫和市場存儲資源
- **資源交易** - 與其他玩家或 AI 進行貿易
- **資源轉換** - 將一種資源轉換為另一種

#### 經濟策略
- **早期發展** - 快速建立經濟基礎
- **平衡發展** - 軍事和經濟並重
- **軍事優先** - 專注於軍事力量
- **防禦優先** - 專注於防禦建設

#### 課程類型
教育模式包含多種課程類型：

**歷史課程**

**軍事課程**

#### 課程進度
每個課程包含：
- **學習目標** - 課程要達到的目標

- **成就獎勵** - 完成課程的獎勵

#### 測驗類型

## 多人遊戲

### 連接設置

#### 創建房間
1. 選擇「多人遊戲」
2. 點擊「創建房間」
3. 設置房間參數：
   - 房間名稱
   - 最大玩家數（2-8人）
   - 地圖選擇
   - 遊戲模式
   - 密碼保護（可選）
4. 點擊「創建」完成設置

#### 加入房間
1. 選擇「多人遊戲」
2. 點擊「加入房間」
3. 輸入房間 ID 或搜索房間
4. 輸入密碼（如果需要）
5. 點擊「加入」進入遊戲

## 常見問題

### 技術問題

**Q: 遊戲啟動時崩潰怎麼辦？**
A: 嘗試以下解決方案：
1. 更新顯卡驅動程序
2. 檢查系統是否滿足最低要求
3. 關閉後台程序釋放內存
4. 驗證遊戲文件完整性

**Q: 網絡連接不穩定？**
A: 檢查以下項目：
1. 網絡連接質量和速度
2. 防火牆設置是否阻擋遊戲
3. 路由器配置是否正確
4. 使用有線連接替代無線

**Q: VR/AR 功能無法使用？**
A: 確認以下設置：
1. VR/AR 設備是否正確連接
2. 驅動程序是否為最新版本
3. 遊戲 VR/AR 設置是否啟用
4. 工作空間是否足夠大

### 遊戲問題

**Q: 如何快速獲得資源？**
A: 推薦以下策略：
1. 建設多個資源收集建築
2. 升級資源收集效率
3. 控制重要資源點
4. 與其他玩家進行貿易

**Q: AI 對手太強/太弱？**
A: 調整 AI 難度：
1. 在設置中調整 AI 難度等級
2. 選擇適合自己水平的遊戲模式
3. 從簡單難度開始逐步提升
4. 學習 AI 的行為模式

**Q: 教育模式進度如何保存？**
A: 進度保存機制：
1. 遊戲自動保存教育進度
2. 可手動保存特定課程進度
3. 雲端同步跨設備進度
4. 查看詳細的學習統計報告
