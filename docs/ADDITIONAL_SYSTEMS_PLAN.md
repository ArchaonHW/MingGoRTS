## Epic 9.1: VR/AR支持系統

### 系統概述

為MingGoRTS提供虛擬現實(VR)和增強現實(AR)支持，讓玩家能以沉浸式方式體驗遊戲。

### 技術架構

```
┌─────────────────────────────────────────────────────────────────┐
│                      VR/AR Support System                       │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│  │ VR Core      │  │ AR Core      │  │ Mixed Reality│          │
│  │ (VR核心)     │  │ (AR核心)     │  │ (混合現實)   │          │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘          │
│         │                  │                  │                 │
│  ┌──────▼──────────────────▼──────────────────▼───────┐          │
│  │           HMD Manager (頭顯管理器)                  │          │
│  └──────┬──────────────────┬──────────────────┬───────┘          │
│         │                  │                  │                 │
│  ┌──────▼──────┐   ┌──────▼──────┐   ┌──────▼──────┐           │
│  │ Input       │   │ Rendering   │   │ Tracking    │           │
│  │ (輸入處理)  │   │ (渲染管線)  │   │ (追蹤系統)  │           │
│  └─────────────┘   └─────────────┘   └─────────────┘           │
└─────────────────────────────────────────────────────────────────┘
```

### 核心組件

#### 1. MingRTSVRSupport - VR支持核心

**文件**: `MingRTSVRSupport.h/.cpp`

**功能規格**:
| 功能 | 描述 | 技術要求 |
|------|------|----------|
| HMD檢測 | 自動檢測VR頭顯連接 | OpenVR/Oculus SDK |
| 立體渲染 | 雙眼分離渲染 | 單眼90FPS+ |
| 視角控制 | 頭部追蹤控制視角 | 6DOF追蹤 |
| 空間定位 | 房間規模或固定位置 | 2m x 1.5m最小空間 |
| 舒適選項 | 平滑轉向/瞬間轉向 | 減少暈眩 |
| IPD調整 | 瞳距自適應 | 58-72mm範圍 |

## Epic 12.1: Replay/回放系統

### 系統概述

錄製、回放和分析對戰過程，支持學習和分享。

### 核心組件

#### 1. MingRTSReplayRecorder - 回放錄製器

**文件**: `MingRTSReplayRecorder.h/.cpp`

**錄製內容**:
| 數據類型 | 內容 | 頻率 |
|----------|------|------|
| 命令流 | 玩家所有操作指令 | 即時 |
| 隨機種子 | RNG初始狀態 | 開始時 |
| 遊戲設定 | 地圖/模式/參數 | 開始時 |
| 關鍵幀 | 每30秒保存完整遊戲狀態 | 30秒間隔 |
| 元數據 | 玩家ID/版本/時長 | 結束時 |

**壓縮策略**:
- 只記錄玩家輸入，非完整畫面
- 平均1小時對戰 = 5-10MB回放文件
- 使用LZ4實時壓縮

#### 2. MingRTSReplayPlayer - 回放播放器

**播放功能**:
| 功能 | 描述 | 快捷鍵 |
|------|------|--------|
| 播放/暫停 | 控制回放狀態 | Space |
| 快進/快退 | 2x/4x/8x/0.5x速度 | +/- |
| 跳轉時間 | 跳到指定時間點 | T |
| 視角切換 | 切換觀察玩家 | 1-12 |
| 自由視角 | 脫離玩家視角自由觀察 | F |
| 時間軸 | 顯示關鍵事件標記 | - |

#### 3. MingRTSReplayAnalyzer - 回放分析器

**分析功能**:
```
回放分析報告
├── 宏觀統計
│   ├── APM (每分鐘操作數) 趨勢圖
│   ├── 經濟曲線 (資源採集/消耗)
│   ├── 兵力對比時間線
│   └── 地圖控制百分比
├── 關鍵時刻
│   ├── 大規模戰鬥標記
│   ├── 經濟/科技轉折點
│   ├── 決策分支點
│   └── 失誤/亮點自動識別
├── 戰術分析
│   ├── 開局策略分類
│   ├── 兵種組合分析
│   ├── 戰術執行效率
│   └── 對比同段位平均數據
└── 改進建議
    ├── 經濟優化建議
    ├── 操作效率提升
    └── 戰術選擇建議
```

| 離線掛機 | 行為異常檢測 | 收益清零 |

**處罰等級**:
| 等級 | 行為 | 處罰 |
|------|------|------|

| 封禁 | 確定違規 | 30天封禁 |
| 永久封禁 | 嚴重違規 | 永久封禁+設備封禁 |

- 異常操作標記審核
