# Epic 6.2.1 国民政府美术概念设计

## 设计目标

为国民政府势力创建现代化、机械化、革命性的视觉风格，体现其作为中国现代化先驱的特征。

**工期**: 5工作日  
**产出**: 风格指南PDF + 概念草图集 + 参考图库

---

## 第一部分: 视觉风格指南

### 1.1 色彩系统

#### 主色调
| 颜色 | 色值 | 用途 | 历史依据 |
|------|------|------|----------|
| **青天蓝** | #1E88E5 | 制服/旗帜主色 | 青天白日满地红 - 青天 |
| **白日白** | #FFFFFF | 徽章/装饰 | 青天白日徽 |
| **满地红** | #C62828 | 点缀/旗帜 | 中华民国国旗底色 |
| **钢灰** | #607D8B | 机械化装备 | 现代工业化 |
| **黄铜** | #BCAAA4 | 金属装饰 | 军官徽章 |

#### 色彩比例
```
主色 (50%): 青天蓝 / 钢灰
辅色 (35%): 白日白 / 满地红
点缀 (15%): 黄铜 / 黑色
```

### 1.2 视觉特征关键词

#### 核心风格
- **革命先锋**: 打破旧秩序，建立新国家
- **现代化**: 机械化、工业化、西方化
- **民族主义**: 爱国、团结、抗外侮
- **军事精英**: 黄埔军校、德式训练

#### 设计语言
- 简洁明快的线条
- 对称与秩序
- 蓝白红三色主导
- 机械化装备大量出现

## 第二部分: 单位概念设计

### 2.1 黄埔步兵 (Whampoa Infantry)

#### 角色设定
- **身份**: 国民革命军核心步兵
- **时期**: 1924-1949年
- **特点**: 受过德式/苏式训练，装备现代化

#### 视觉元素
```
头部:
- 德式钢盔 (M35式，青天白日徽)
- 或布制军帽 (青天白日帽徽)

上身:
- 青天蓝色制服
- 白色领章 (军官)
- 金属纽扣
- 胸挂弹药带

下身:
- 同色系长裤
- 绑腿 (深蓝色)
- 胶鞋或皮靴

装备:
- 中正式步枪 (仿毛瑟98K)
- 手榴弹
- 帆布背包
```

### 2.2 机械化步兵 (Mechanized Infantry)

#### 角色设定
- **身份**: 德械师/美械师精锐部队
- **特点**: 装备先进，摩托化/机械化运输

#### 视觉元素
```
头部:
- 德式M35钢盔 (优质钢材)
- 护目镜 (驾驶员/摩托车兵)

上身:
- 深灰蓝色制服 (更贴身)
- 皮质装备带
- 防毒面具包

装备:
- 冲锋枪 (MP18/汤姆逊)
- 摩托车/装甲车伴随
- 无线电设备
```

### 2.3 炮兵部队 (Artillery Corps)

#### 角色设定
- **身份**: 德式炮兵，装备先进火炮
- **特点**: 技术兵种，火力强大

#### 视觉元素
```
头部:
- M35钢盔
- 耳机 (炮手)

上身:
- 加厚工作服
- 皮质护肩

装备:
- 德制75mm山炮
- 美制105mm榴弹炮 (后期)
- 观测设备
```

### 2.4 战车部队 (Armored Unit)

#### 角色设定
- **身份**: 装甲兵，中国首批坦克部队
- **特点**: 现代化装备，稀缺但精锐

#### 视觉元素
```
载具:
- 德制Panzer I (初期)
- 苏制T-26 (中期)
- 美制M4 Sherman (后期)

车组成员:
- 黑色皮质坦克帽
- 连体工作服
- 护目镜
```

### 2.5 空军飞行员 (Air Force Pilot)

#### 角色设定
- **身份**: 中华民国空军飞行员
- **特点**: 精英中的精英，国际援助

#### 视觉元素
```
飞行服:
- 棕色皮质飞行夹克
- 白色丝绸围巾
- 飞行头盔
- 护目镜

标志:
- 机翼徽章
- 飞虎队标志 (美式)
```

## 第三部分: 建筑概念设计

### 3.1 总统府/行政院 (Presidential Office)

#### 建筑定位
- **功能**: 国民政府行政中心
- **风格**: 现代政府建筑，庄重威严

#### 设计元素
```
建筑风格:
- 新古典主义 + 现代主义
- 白色主体 + 蓝色屋顶
- 青天白日满地红旗帜
- 柱廊和对称布局

标志性元素:
- 南京总统府样式
- 大型广场
- 孙中山铜像
```

### 3.2 黄埔军校 (Whampoa Military Academy)

#### 建筑定位
- **功能**: 军事教育，革命摇篮
- **风格**: 中西合璧，革命氛围

#### 设计元素
```
建筑风格:
- 广州黄埔军校旧址风格
- 红色砖墙 (革命象征)
- 白色装饰线条
- 革命标语和旗帜

功能设施:
- 大操场 (誓师北伐场景)
- 教室 (三民主义教育)
- 学员宿舍
```

### 3.3 兵工厂 (Arsenal)

#### 建筑定位
- **功能**: 武器生产，工业基础
- **风格**: 现代工业建筑

#### 设计元素
```
建筑风格:
- 工业化厂房
- 烟囱和吊车
- 钢架结构
- 德式工业风格

生产设施:
- 步枪生产线
- 弹药车间
- 组装工厂
```

### 3.4 空军基地 (Air Force Base)

#### 建筑定位
- **功能**: 空军作战基地
- **风格**: 现代军事基地

#### 设计元素
```
设施:
- 跑道和机库
- 塔台
- 防空炮位
-  barracks

标志性元素:
- 飞机涂装 (青天白日徽)
- 美国援助标志 (飞虎队)
```

### 3.5 孙中山纪念堂 (Sun Yat-sen Memorial)

#### 建筑定位
- **功能**: 精神象征，政治中心
- **风格**: 纪念性建筑，庄严肃穆

#### 设计元素
```
建筑风格:
- 广州中山纪念堂风格
- 八角形建筑
- 蓝色琉璃瓦
- 宏伟柱廊

内部:
- 孙中山坐像
- 三民主义标语
- 青天白日满地红旗
```
