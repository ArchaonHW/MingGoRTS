```

           ↓

           ├── DLC 1: 晚清風雲 (1840-1911)

           ├── DLC 4: 現代風雲 (1950-2000)
```

#### 概念設定

**原創科幻奇幻跨界世界觀** (東方科幻 + 異界冒險)

民國軍隊穿越到原創異界宇宙：
- **設定**：民國時期國軍在一次神秘實驗中穿越到異次元宇宙
- **背景**：發現多元宇宙中存在無數「界域」，每個界域有獨特法則
- **衝突**：遭遇企圖入侵地球維度的「虛空帝國」
- **融合**：民國現代化戰術 vs 異界魔法與科技

**世界觀要素**：
- **星界航路**：連接各個界域的虛空通道
- **界域法則**：不同世界有不同物理和魔法法則
- **虛空帝國**：跨維度征服者，擁有改造生物和機械的混合部隊
- **自由聯盟**：抵抗虛空帝國的異界勢力聯合體
