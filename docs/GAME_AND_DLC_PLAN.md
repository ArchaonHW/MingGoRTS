### DLC 1: 晚清風雲 (1840-1911)

**發布時間**: 基礎遊戲後3個月  
**定價**: $19.99 / ¥98  
**開發週期**: 3個月  

#### 新增內容

| 類別 | 數量 | 說明 |
|------|------|------|
| **時間跨度** | 71年 | 鴉片戰爭到辛亥革命 |
| **可玩勢力** | 10+ | 清朝、太平天國、英法列強、日本、各地督撫 |
| **歷史人物** | 40+ | 慈禧、李鴻章、曾國藩、洪秀全、袁世凱(年輕) |
| **主線劇情** | 8章 | 鴉片戰爭 → 太平天國 → 洋務運動 → 甲午戰爭 → 維新 → 義和團 → 新政 → 革命 |
| **新機制** | 3+ | 不平等條約系統、列強干涉機制、改革現代化 |
| **單位類型** | 30+ | 八旗兵、湘軍、淮軍、太平軍、西式新軍、列強軍隊 |
| **建築** | 20+ | 江南製造局、北洋水師基地、租界建築 |
| **地圖** | 擴展 | 包含東南亞、日本、部分歐洲 |

#### 特色機制

**不平等條約系統**
- 戰敗後被迫簽訂條約
- 割地賠款影響國家發展
- 可通過外交或軍事手段廢除
- 列強勢力範圍爭奪

**列強干涉機制**
- 英國、法國、俄國、日本AI勢力
- 可選擇親近不同列強獲得援助
- 列強間的博弈影響中國局勢
