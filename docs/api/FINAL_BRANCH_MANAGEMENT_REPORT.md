## 🛡️ 主分支保護機制

### 保護規則
1. **禁止直接提交**: 不允許直接提交到 main 分支
2. **強制預檢查**: 合併前必須通過所有檢查
3. **測試要求**: 所有測試必須通過
4. **構建要求**: 項目必須成功構建
5. **乾淨狀態**: 工作目錄必須乾淨

### 檢查流程
```
合併請求 → 預檢查系統 → 驗證通過 → 執行合併 → 推送變更
    ↓           ↓           ↓           ↓           ↓
  用戶請求    工作目錄檢查   測試檢查    構建檢查    合併完成
             分支更新檢查   安全掃描    文檔檢查    自動清理
```

## 🔄 工作流程設計

### 標準開發流程
1. **初始化**: `.\Quick-Branch-Start.ps1 -Action init`
2. **創建功能分支**: `.\Quick-Branch-Start.ps1 -Action feature`
3. **開發功能**: 在功能分支上進行開發
4. **預檢查**: `.\Quick-Branch-Start.ps1 -Action checks`
5. **合併到開發**: `.\Quick-Branch-Start.ps1 -Action merge`
6. **發布準備**: 從 develop 創建 release 分支
7. **合併到主**: 最終合併到 main 分支

### 分支命名規範
- **功能分支**: `feature/<feature-name>`
- **熱修復分支**: `hotfix/<hotfix-name>`
- **發布分支**: `release/<version>`
- **主分支**: `main`
- **開發分支**: `develop`
