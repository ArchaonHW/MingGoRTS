# 北洋炮兵单位3D制作技术文档

**资产名称**: SM_Beiyang_Artillery  
**资产类型**: 炮兵单位 (RTS游戏)

## 第一部分: 概念与参考

### 1.1 历史背景
北洋炮兵装备德式克虏伯山炮，是北洋军中技术含量最高的兵种。炮兵需要多人操作火炮，团队协作完成射击流程。

### 1.2 视觉参考图
```
参考来源:

关键参考点:

## 第五部分: 技术特效

### 5.1 火炮特效

```
射击特效:
- 炮口火焰 (Muzzle Flash)
- 炮口烟雾 (Smoke)
- 地面烟尘 (Dust)
- 后坐震动 (Camera Shake)

装填特效:
- 开闩烟雾 (残留火药气体)
- 炮弹入膛闪光

命中特效:
- 爆炸效果
- 弹坑贴花
- 碎片效果
```

### 5.2 音效触发点

```
动画通知:
- Setup_Complete: 机械锁定声
- Fire: 炮击声 + 爆炸声
- Load_Shell: 金属碰撞声
- Close_Breech: 机械闭合声
```

- Moving: 移动中

```
炮兵技能:
