# Epic 6 全势力3D美术资产制作总指南

## 概述

**目标**: 为12个势力创建统一的3D美术资产制作规范和流程  
**适用范围**: 所有势力的单位模型、建筑模型、UI资产  
**制作周期**: 约10个月  
**团队配置**: 建议8-10人美术团队

---

## 第一部分: 制作流程规范

### 1.1 标准制作流程 (SOP)

```
阶段1: 概念确认 (1-2天)
  ├─ 审核概念设计文档
  ├─ 确定技术可行性
  ├─ 制定详细制作计划
  └─ 分配具体任务

阶段2: 高模制作 (3-5天/单位)
  ├─ ZBrush/Maya高模雕刻
  ├─ 细节表现
  ├─ 历史准确性验证
  └─ 内部审核

阶段3: 低模拓扑 (1-2天/单位)
  ├─ 按LOD规范拓扑
  ├─ UV展开
  ├─ 烘焙准备
  └─ 面数验证

阶段4: 贴图制作 (2-3天/单位)
  ├─ Substance Painter烘焙
  ├─ PBR材质制作
  ├─ 细节绘制
  └─ 历史纹理参考

阶段5: 骨骼绑定 (1天/单位)
  ├─ 骨骼创建
  ├─ 权重绘制
  ├─ 控制器设置
  └─ RTS适配

阶段6: 动画制作 (2-3天/单位)
  ├─ 基础动画循环
  ├─ 战斗动画
  ├─ 特殊动作
  └─ 动画调试

阶段7: 引擎导入 (1天/单位)
  ├─ FBX导出
  ├─ UE导入
  ├─ 材质连接
  └─ 测试验证

阶段8: 优化迭代 (持续)
  ├─ 性能测试
  ├─ 视觉优化
  ├─ LOD调整
  └─ 最终验收
```

### 1.2 审核节点

| 节点 | 审核人 | 审核内容 |
|------|--------|----------|
| 概念确认 | 美术总监+历史顾问 | 风格+历史准确性 |
| 高模完成 | 主美 | 造型+细节 |
| 低模完成 | 技术美术 | 面数+拓扑 |
| 贴图完成 | 材质组长 | PBR质量 |
| 动画完成 | 动画主管 | 流畅度+RTS适配 |
| 引擎导入 | 技术美术 | 性能+显示 |
| 最终验收 | 制作人+美术总监 | 整体质量 |

## 第二部分: 技术标准详细规范

### 2.1 模型面数标准

#### 单位模型面数 (含LOD)

| LOD | 距离 | 面数上限 | 用途 |
|-----|------|----------|------|
| LOD0 | 0-10m | 10,000-15,000 | 特写、截图 |
| LOD1 | 10-30m | 5,000-7,500 | 常规游戏 |
| LOD2 | 30-100m | 2,500-3,750 | 中远距离 |
| LOD3 | 100m+ | 1,000-1,500 | 远距离 |

#### 建筑模型面数

| 建筑类型 | LOD0面数 | LOD1面数 | LOD2面数 |
|----------|----------|----------|----------|
| 小型 (兵营/民居) | 30,000 | 15,000 | 7,500 |
| 中型 (官署/工厂) | 50,000 | 25,000 | 12,500 |
| 大型 (总统府/军校) | 80,000 | 40,000 | 20,000 |

### 2.2 UV展开规范

```
UV利用率: > 80%
接缝位置: 隐蔽处 (腋下、腿部内侧等)
重叠限制: 不重叠 (除非镜像对称)
Texel密度: 统一 (建议 10-20 pixels/cm)

UV布局:
- 主要部件占据较大UV空间
- 次要部件可适当缩小
- 细节部位优先保证质量
```

### 2.3 PBR材质标准

#### 贴图分辨率

| 资产类型 | 基础色/法线 | 金属度/粗糙度/AO | 特殊贴图 |
|----------|-------------|------------------|----------|
| 单位 | 2048x2048 | 1024x1024 (合并) | 512x512 |
| 建筑 | 4096x4096 | 2048x2048 (合并) | 1024x1024 |
| UI | 512x512/256x256 | - | - |

#### 贴图命名规范
```
格式: [Faction]_[Type]_[AssetName]_[MapType]

示例:
- BY_Unit_Infantry_Albedo.png
- BY_Unit_Infantry_Normal.png
- BY_Unit_Infantry_MRAO.png (Metallic/Roughness/AO合并)

MRAO通道分配:
- R: Metallic
- G: Roughness  
- B: AO
```

#### 材质参数范围

| 参数 | 范围 | 说明 |
|------|------|------|
| Metallic | 0.0 - 1.0 | 0=非金属, 1=纯金属 |
| Roughness | 0.0 - 1.0 | 0=镜面, 1=完全粗糙 |
| AO | 0.0 - 1.0 | 环境光遮蔽强度 |
| Opacity | 0.0 - 1.0 | 透明度 (用于头发等) |
| Emissive | 0.0 - 1.0 | 自发光强度 |

### 2.4 骨骼绑定规范

#### 标准骨骼结构

```
Root (根节点)
  └─ Pelvis (骨盆)
      ├─ Spine1 (脊椎1)
      │   └─ Spine2 (脊椎2)
      │       ├─ Neck (颈部)
      │       │   └─ Head (头部)
      │       ├─ L_Clavicle (左锁骨)
      │       │   └─ L_UpperArm (左上臂)
      │       │       └─ L_LowerArm (左前臂)
      │       │           └─ L_Hand (左手)
      │       │               ├─ L_Finger1...
      │       └─ R_Clavicle (右锁骨)
      │           └─ ... (对称)
      ├─ L_Thigh (左大腿)
      │   └─ L_Calf (左小腿)
      │       └─ L_Foot (左脚)
      │           └─ L_Toe (左脚趾)
      └─ R_Thigh (右大腿)
          └─ ... (对称)

总计: 约60-70根骨骼 (含手指)
```

#### 权重绘制规范
- 每个顶点最多受4根骨骼影响
- 权重总和必须等于1.0
- 关节处需平滑过渡
- 避免刚性权重

#### 武器/装备挂接点
```
Socket命名:
- Socket_Weapon_R (右手武器)
- Socket_Weapon_L (左手武器/盾牌)
- Socket_Head (头部装备)
- Socket_Back (背部装备)
```

### 2.5 RTS动画规范

#### 必备动画列表

| 动画 | 长度 | 循环 | 说明 |
|------|------|------|------|
| Idle_A | 60-120帧 | 是 | 待机基础 |
| Idle_B | 60-120帧 | 是 | 待机变体 |
| Walk | 30-60帧 | 是 | 行走 |
| Run | 20-30帧 | 是 | 奔跑 |
| Attack | 30-60帧 | 否 | 攻击 |
| Attack_Heavy | 45-75帧 | 否 | 重攻击 |
| Damage | 20-30帧 | 否 | 受击 |
| Death | 60-120帧 | 否 | 死亡 |
| Victory | 120-180帧 | 否 | 胜利庆祝 |
| Deploy | 60-120帧 | 否 | 部署/展开 |

#### 动画导入设置
```
UE导入设置:
- 帧率: 30 FPS
- 骨骼: 使用自定义骨骼
- 缩放: 1.0
- 坐标系: Y-up (Maya/Maya规范)
- 单位: 厘米
```

## 第三部分: 各势力制作要点

### 3.1 北洋政府 (Beiyang)

#### 制作重点
- **德式严谨**: 制服线条整齐，装备标准化
- **中西合璧**: 中式元素(立领)+西式剪裁
- **北洋灰蓝**: 色彩必须准确 (参考Feldgrau变种)

#### 难点提示
- 德式军帽细节 (M1907式)
- 中式立领与西式肩章结合
- 总统府中西合璧建筑风格

#### 参考资源
- 袁世凯练兵图
- 保定军校照片
- 北洋军阅兵影像

### 3.2 国民政府 (Nationalist)

#### 制作重点
- **青天白日**: 蓝白红三色系统
- **现代化**: 德械师装备，钢盔
- **黄埔精神**: 军装整齐，士气高昂

#### 难点提示
- 德式M35钢盔配青天白日徽
- 机械化部队装备差异
- 空军飞行员夹克质感

#### 参考资源
- 黄埔军校历史照片
- 德械师装备图鉴
- 抗战国军影像

### 3.3 共产党 (Communist)

#### 制作重点
- **工农本色**: 粗糙布料，草鞋
- **红五星**: 无处不在的红色元素
- **根据地**: 土布、绑腿、简陋装备

#### 难点提示
- 八角帽独特造型
- 草鞋和绑腿细节
- 窑洞建筑风格

#### 参考资源
- 红军长征照片
- 延安时期影像
- 瑞金苏区资料

### 3.4 军阀势力 (Warlords)

#### 制作重点 (七个军阀各有特色)

**奉系**: 狗皮帽子、东北大棉袄、深绿色  
**直系**: 灰蓝色、文人气质、关羽元素  
**皖系**: 北洋正统、深褐色、陆军部风格  
**晋系**: 土黄色、山西特色、阎锡山个人元素  
**桂系**: 深绿色、广西狼兵、短裤绑腿  
**滇系**: 藏蓝色、法式影响、多民族  
**川系**: 灰色、斗笠、川军草鞋兵

#### 难点提示
- 七个军阀差异化明显但需统一品质
- 地域特色准确表现
- 避免刻板印象

### 3.5 马家军 (Ma Family)

#### 制作重点
- **伊斯兰元素**: 白色礼拜帽、绿色新月
- **回族特色**: 宗教标识、清真元素
- **西北骑兵**: 强悍骑兵传统

#### 难点提示
- 宗教敏感性 (清真寺、宗教符号)
- 回族服饰准确性
- 伊斯兰建筑风格

#### 注意
- 需文化顾问审核
- 保持尊重和准确性

### 3.6 新疆势力 (Xinjiang)

#### 制作重点
- **多民族融合**: 维吾尔、哈萨克、汉族等
- **中亚风情**: 丝绸之路元素
- **苏联影响**: 盛世才时期苏式建筑

#### 难点提示
- 多民族服饰差异
- 苏式建筑风格
- 维吾尔建筑特色

#### 注意
- 民族敏感性
- 政治中立性
- 文化准确性

## 第七部分: 质量管控

### 7.1 质量检查清单

#### 模型检查
- [ ] 面数符合LOD规范
- [ ] 拓扑合理，无三角面过多
- [ ] UV利用率>80%
- [ ] 无重叠UV (除非设计)
- [ ] 法线方向正确
- [ ] 缩放统一 (1.0)
- [ ] 原点位置正确
- [ ] 命名规范

#### 材质检查
- [ ] PBR贴图完整
- [ ] 分辨率符合规范
- [ ] 无接缝 (Seamless)
- [ ] 色彩空间正确 (Linear/sRGB)
- [ ] 压缩格式正确
- [ ] 命名规范

#### 动画检查
- [ ] 骨骼层级正确
- [ ] 权重绘制平滑
- [ ] 动画循环无缝
- [ ] 帧率统一 (30FPS)
- [ ] 无穿插、抖动
- [ ] RTS系统兼容

#### 引擎检查
- [ ] 导入无错误
- [ ] 材质正确连接
- [ ] LOD自动切换
- [ ] 碰撞体正确
- [ ] 性能达标

### 7.2 历史准确性验证

#### 审核流程
1. **概念阶段**: 历史顾问审核设计方向
2. **高模阶段**: 审核装备、服饰细节
3. **贴图阶段**: 审核色彩、纹理历史准确性
4. **最终阶段**: 全面历史审核

#### 常见问题
- 武器装备时代错误
- 服饰款式年代混淆
- 建筑元素混搭错误
- 徽章旗帜错误
