## 🎮 遊戲概述

### 什麼是MingGoRTS？
MingGoRTS是一款以民國時期為背景的即時戰略遊戲，融合了歷史真實性和策略深度。玩家可以選擇12個不同的歷史勢力，體驗從1912年到1949年的中國近代史。

### 遊戲特色
- **12個可玩勢力** - 每個勢力都有獨特的玩法和特色機制
- **歷史真實性** - 基於真實歷史事件和人物
- **深度策略** - 複雜的經濟、外交和軍事系統
- **現代化UI** - 直觀的用戶界面和豐富的視覺效果
- **多語言支持** - 支持10種語言

### 遊戲模式
- **單人戰役** - 體驗完整的故事情節
- **多人對戰** - 與其他玩家對抗
- **合作模式** - 與朋友共同完成目標
- **自定義戰役** - 創建自己的戰役

## 💻 系統要求

### 最低配置
- **操作系統**: Windows 10 64位
- **處理器**: Intel Core i3-3220 或 AMD FX-6350
- **內存**: 4GB RAM
- **顯卡**: NVIDIA GeForce GTX 660 或 AMD Radeon HD 7850
- **存儲空間**: 10GB 可用空間
- **DirectX**: 版本 11

### 推薦配置
- **操作系統**: Windows 10/11 64位
- **處理器**: Intel Core i5-6600K 或 AMD Ryzen 5 2600
- **內存**: 8GB RAM
- **顯卡**: NVIDIA GeForce GTX 1060 或 AMD Radeon RX 580
- **存儲空間**: 15GB 可用空間
- **DirectX**: 版本 12

### 最佳配置

## 🔧 故障排除

### 常見問題
#### 啟動問題
**問題**: 遊戲無法啟動
**解決方案**:
1. 檢查系統要求
2. 更新顯卡驅動
3. 驗證文件完整性
4. 以管理員身份運行

#### 性能問題
**問題**: 遊戲運行緩慢
**解決方案**:
1. 降低圖像設置
2. 關閉背景程序
3. 更新系統驅動
4. 檢查系統資源

#### 網絡問題
**問題**: 多人遊戲連接失敗
**解決方案**:
1. 檢查網絡連接
2. 配置防火牆設置
3. 檢查端口設置
4. 重啟路由器

#### 顯示問題
**問題**: 圖像顯示異常
**解決方案**:
1. 更新顯卡驅動
2. 調整圖像設置
3. 檢查顯示器設置
4. 驗證文件完整性

### 錯誤代碼
#### 錯誤代碼 0x0001
**描述**: 內存不足
**解決方案**: 關閉其他程序，增加虛擬內存

#### 錯誤代碼 0x0002
**描述**: 顯卡驅動過時
**解決方案**: 更新顯卡驅動程序

#### 錯誤代碼 0x0003
**描述**: 文件損壞
**解決方案**: 驗證文件完整性，重新安裝

#### 錯誤代碼 0x0004
**描述**: 網絡連接失敗
**解決方案**: 檢查網絡設置，配置防火牆

#### 系統優化
1. **關閉不必要的程序**
