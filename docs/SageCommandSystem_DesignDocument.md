# 至聖者指揮學 - 遊戲系統開發文檔

## 系統概述

**至聖者指揮學**是一套基於中國傳統哲學（陰陽五行）的指揮理論體系，核心思想是「正邪皆兵，而聖者不墮」。本系統將此理論轉化為 MingGoRTS 的遊戲機制，創造獨特的戰略指揮玩法。

---

## 核心理論架構

### 三層指揮體系

```
┌─────────────────────────────────────────────────────┐
│  卷一：總論 - 指揮之道，不在善惡                      │
│  - 聖者、魔王、偽聖者的本質差異                     │
│  - 指揮 ≠ 行動；指揮 = 切換權                       │
├─────────────────────────────────────────────────────┤
│  卷二：世界模型 - 陰陽五行作為指揮邏輯               │
│  - 陰陽 = 可見 vs 不可見                            │
│  - 五行 = 指揮節奏 (木→火→土→金→水)                │
├─────────────────────────────────────────────────────┤
│  卷三/四：核心武器 - 正逆六策 + 三權模型            │
│  - 正六策：立國、立制、立人                         │
│  - 逆六策：破局、破結構、不破人                     │
│  - 三權：道權、策權、兵權                           │
└─────────────────────────────────────────────────────┘
```

## 遊戲系統設計

### 1. 角色類型系統 (SageCharacterSystem)

基於理論中的三種角色類型：

| 角色類型 | 核心特徵 | 遊戲優勢 | 風險 |
|---------|---------|---------|------|
| **聖者** | 能用而能封 | 正逆策略切換無懲罰 | 初期發展較慢 |
| **魔王** | 能用而不能停 | 逆策效果+50% | 使用逆策後無法停止 |
| **偽聖者** | 不能用卻假裝不用 | 外交加成 | 無法使用逆策 |

### 2. 三權指揮系統 (ThreePowerCommandSystem)

```cpp
// 三權結構
struct FThreePowerSystem {
    // 道權 - 防墮監測
    FSageMoralAuthority MoralAuthority;
    
    // 策權 - 策略切換
    FSageStrategyAuthority StrategyAuthority;
    
    // 兵權 - 執行指揮
    FSageMilitaryAuthority MilitaryAuthority;
};
```

**道權系統功能：**
- 監測玩家的「墮落徵象」
- 三大墮落徵象警告
- 失去資格判準

**策權系統功能：**
- 正逆六策管理
- 陰陽切換決策
- 五行節奏控制

**兵權系統功能：**
- 部隊指揮執行
- 命令發布系統
- 後果承擔機制

### 3. 正逆六策系統 (SixStrategiesSystem)

**正六策（陽/長期/公開）：**

| 策略 | 功能 | 五行對應 | 效果 |
|-----|------|---------|------|
| **立國** | 建立正當性 | 木 | 士氣+30%, 徵兵+20% |
| **立制** | 建立秩序 | 火→土 | 經濟效率+25% |
| **立人** | 培養人才 | 水→木 | 將領成長+40% |

**逆六策（陰/短期/隱蔽）：**

| 策略 | 功能 | 五行對應 | 效果 | 風險 |
|-----|------|---------|------|------|
| **破局** | 扭轉局勢 | 水→木 | 突破包圍/逆轉戰局 | 暴露後信譽-50% |
| **破結構** | 瓦解敵人 | 金→水 | 敵軍內亂+40% | 敵人警覺後失效 |
| **不破人** | 暗控敵人 | 土→金 | 策反敵將 | 被發現後永久封鎖 |

### 4. 五行指揮節奏系統 (WuXingCommandRhythm)

```
木(春/立名) → 火(夏/造勢) → 土(長夏/收權) → 金(秋/裁斷) → 水(冬/養機) → 木(再起)
```

**節奏機制：**
- 每個階段有特定的指揮行動加成
- 五行相生：正確順序獲得連擊加成
- 五行相剋：錯誤順序導致指揮減益

### 5. 防墮機制系統 (AntiFallSystem)

**三大墮落徵象監測：**

1. **內部始疑** - 連續使用逆策後部隊忠誠度下降
2. **敵轉異常** - 敵人AI察覺玩家的逆策模式
3. **事過露跡** - 過去使用的逆策被揭露

**最高戒律：**
- 連續使用逆策超過5次 → 強制進入「墮落」狀態
- 墮落狀態下無法使用正策
- 需要完成「贖罪任務」才能恢復

## 實現路徑

### Phase 1: 核心系統 (4週)

**Week 1-2: 角色類型系統**
- 實現聖者/魔王/偽聖者三種角色類型
- 創建角色特性差異化系統
- 開發角色選擇界面

**Week 3-4: 三權指揮框架**
- 建立道權/策權/兵權基礎架構
- 實現權力分配機制
- 開發指揮鏈系統

### Phase 2: 策略系統 (4週)

**Week 5-6: 正逆六策實現**
- 實現6種正策效果
- 實現6種逆策效果
- 開發策略切換界面

**Week 7-8: 五行節奏系統**
- 實現五行相生相剋機制
- 開發節奏追蹤UI
- 創建節奏效果系統

### Phase 3: 進階機制 (3週)

**Week 9-10: 防墮系統**
- 實現墮落徵象監測
- 開發贖罪機制
- 創建道德邊界系統

**Week 11: AI適配**
- 調整AI以應對正逆策略
- 開發AI察覺逆策的機制
- 實現AI使用正逆策略

### Phase 4: 集成測試 (1週)

**Week 12: 測試與平衡**
- 全系統集成測試
- 數值平衡調整
- 玩家體驗優化

## 核心數值設計

### 正逆策略數值

| 策略類型 | 冷卻時間 | 持續時間 | 效果強度 | 墮落值 |
|---------|---------|---------|---------|-------|
| 立國 (正) | 無 | 永久 | +30% | 0 |
| 立制 (正) | 無 | 永久 | +25% | 0 |
| 立人 (正) | 無 | 永久 | +40% | 0 |
| 破局 (逆) | 30天 | 即時 | 逆轉戰局 | +20 |
| 破結構 (逆) | 45天 | 敵內亂3月 | +40% | +30 |
| 不破人 (逆) | 60天 | 永久策反 | 策反成功 | +40 |

### 墮落機制數值

- 每次使用逆策：+20~40 墮落值
- 墮落值達100：進入「墮落」狀態
- 每次使用正策：-10 墮落值
- 贖罪任務完成：-50 墮落值

### 角色類型修正

| 角色 | 正策效果 | 逆策效果 | 墮落閾值 | 特殊規則 |
|-----|---------|---------|---------|---------|
| 聖者 | 100% | 100% | 150 | 無懲罰切換 |
| 魔王 | 70% | 150% | 200 | 無法停止逆策 |
| 偽聖者 | 120% | 0% | 80 | 無法使用逆策 |
