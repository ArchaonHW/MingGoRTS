## 🎮 使用示例

### 基本網絡操作
```cpp
// 創建網絡會話
FString SessionID = NetworkSystem->CreateNetworkSession(TEXT("MyGame"), EGameMode::Versus, ENetworkType::LAN, 8);

// 加入會話
bool bJoined = NetworkSystem->JoinNetworkSession(SessionID, TEXT("PlayerName"), TEXT("password"));

// 發送網絡消息
NetworkSystem->SendNetworkMessage(TEXT("Hello World!"));

// 同步遊戲數據
TArray<uint8> GameData;
NetworkSystem->SyncData(TEXT("GameState"), GameData, ESyncMode::Full, ENetworkPriority::High);
```

### 玩家管理
```cpp
// 獲取玩家列表
TArray<FNetworkPlayer> Players = NetworkSystem->GetPlayerList();

// 設置玩家準備狀態
NetworkSystem->SetPlayerReady(PlayerID, true);

// 踢出玩家
NetworkSystem->KickPlayer(PlayerID, TEXT("Inappropriate behavior"));

// 獲取玩家延遲
float Ping = NetworkSystem->GetPing(PlayerID);
```

### 網絡監控
```cpp
// 獲取網絡統計
TMap<FString, float> Stats = NetworkSystem->GetNetworkStatistics();

// 檢查網絡連接
bool bConnected = NetworkSystem->IsNetworkConnected();

// 獲取帶寬使用
int32 Bandwidth = NetworkSystem->GetBandwidthUsage();

// 優化網絡性能
NetworkSystem->OptimizeNetworkPerformance();
```
