## 第一部分: 概念与参考

### 1.1 历史背景
北洋军官是北洋军中的精英阶层，多毕业于保定军校或国外军事院校，是军队的核心指挥力量。军官着装华丽，佩戴勋章，体现其身份地位。

### 1.2 视觉参考图
```
参考来源:

- 保定军校毕业照
- 德国军事顾问服装影响
- 清代遗留下来的军衔徽章

关键参考点:
- 华丽军服 (金色装饰)
```

- 威严华贵
- 精英气质
- 指挥风采

- 权威象征

```cpp
// UE5导入设置 - 军官单位 (英雄级)
```

## 第六部分: 游戏机制

### 6.1 军官属性

```
基础属性:
- Health: 200 (高血量)
- Damage: 35 (佩剑) / 25 (手枪)
- Speed: 280 (中等)
- Armor: 中等

特殊属性:
- 士气加成: 周围友军+15%士气
- 指挥范围: 500单位半径
- 复活时间: 60秒 (珍贵单位)
```

### 6.2 技能系统

```
主动技能:
1. 冲锋号令 (Charge Command)
   - 冷却: 60秒
   - 效果: 范围内友军移速+30%，伤害+20%，持续10秒
   - 动画: A_Officer_Command_Charge

2. 坚守阵地 (Hold Position)
   - 冷却: 45秒
   - 效果: 范围内友军防御+25%，持续15秒
   - 动画: A_Officer_Command_Hold

3. 战术撤退 (Tactical Retreat)
   - 冷却: 90秒
   - 效果: 范围内友军移速+40%，受到伤害-15%，持续8秒
   - 动画: A_Officer_Command_Retreat

被动技能:
- 领导力: 自动提升周围部队效率
- 不屈意志: 生命值低于30%时，防御+20%
- 战术大师: 视野范围+50%
```
