# Epic 6.1.1 北洋政府美术概念设计

## 设计目标

为北洋政府势力创建完整的视觉风格指南和概念设计文档，确保所有美术资产风格统一、历史准确、符合RTS游戏需求。

**工期**: 5工作日  
**产出**: 风格指南PDF + 概念草图集 + 参考图库

---

## 第一部分: 视觉风格指南

### 1.1 色彩系统

#### 主色调
| 颜色 | 色值 | 用途 | 历史依据 |
|------|------|------|----------|
| **北洋灰** | #5A6C7D | 制服主色 | 德式Feldgrau改良 |
| **深灰蓝** | #4A5568 | 建筑外墙 | 北洋军服实际颜色 |
| **金色** | #D69E2E | 装饰/徽章 | 军官肩章金色 |
| **暗红色** | #9B2C2C | 点缀/室内 | 传统中式红 |
| **象牙白** | #F7FAFC | 建筑细节 | 欧式建筑白色装饰 |

#### 色彩比例
```
主色 (60%): 北洋灰 / 深灰蓝
辅色 (30%): 金色 / 暗红色
点缀 (10%): 象牙白 / 黑色
```

### 1.2 视觉特征关键词

#### 核心风格
- **中西合璧**: 中国传统元素 + 西方军事风格
- **德式严谨**: 整齐的制服、对称的建筑布局
- **民国初建**: 新旧交替的时代感
- **中央正统**: 庄重、威严、规范

#### 设计语言
- 直线为主，少量曲线装饰
- 对称构图，体现秩序感
- 材质对比 (粗糙石材 vs 光滑金属)
- 层次分明 (前景清晰、背景大气)

## 第二部分: 单位概念设计

### 2.1 北洋步兵

#### 角色设定
- **身份**: 北洋陆军普通士兵
- **时期**: 1912-1928年
- **特点**: 训练有素但装备参差不齐

#### 视觉元素
```
头部:
- 德式军帽 (M1907式) - 灰蓝色，帽徽五色星
- 或传统瓜皮帽 (后期部队)

上身:
- 灰蓝色制服外套 (中式立领+西式剪裁)
-  brass纽扣 (黄铜色)
- 胸前三道褶皱 (德式风格)

下身:
- 同色系长裤
- 绑腿 (灰色布料)
- 布鞋或低筒皮靴

装备:
- 毛瑟Gewehr 98步枪
- 皮质弹药袋
- 水壶和干粮包
```

#### 姿态参考
- 站姿: 德式军姿 (挺胸、收腹、双手贴裤缝)
- 持枪: 斜挎步枪或持枪站立
- 行进: 正步走或快步走

### 2.2 北洋骑兵

#### 角色设定
- **身份**: 北洋骑兵部队
- **特点**: 机动性强，多来自蒙古或华北

#### 视觉元素
```
骑手:
- 灰蓝色骑兵制服 (更贴身)
- 皮质护腿
- 马刀挂于腰侧

马匹:
- 蒙古马品种 (体型较小，耐力好)
- 棕色/黑色/枣红色
- 皮质马鞍 (中式样式)
- 马镫和缰绳

装备:
- 中式马刀 (柳叶刀样式)
- 毛瑟C96手枪 (部分军官)
- 皮质水囊
```

### 2.3 北洋炮兵

#### 角色设定
- **身份**: 炮兵部队技术兵种
- **特点**: 专业化程度高，装备德式火炮

#### 视觉元素
```
头部:
- 德式钢盔原型 (M1916式早期版本)
- 或布制军帽加厚版

上身:
- 加厚灰蓝制服 (便于操作)
- 皮质护肩 (搬运炮弹)
- 工具腰带

装备:
- 75mm克虏伯野战炮 (德式)
- 炮弹箱 (木质，绿色)
- 瞄准工具和炮刷
```

### 2.4 北洋军官

#### 角色设定
- **身份**: 北洋军中级军官 (校官)
- **特点**: 受过德式军事教育，指挥部队

#### 视觉元素
```
头部:
- 大盖帽 (帽檐更大，金色饰带)
- 或德式尖顶盔 (礼服场合)

上身:
- 深灰色礼服制服
- 金色肩章 (军衔标识)
- 金色领章
- 勋章绶带 (胸前)

下身:
- 深色马裤
- 高筒皮靴 (擦亮)

装备:
- 毛瑟C96手枪 (盒子炮)
- 皮质公文包
- 望远镜 (德国蔡司)
- 指挥刀 (西式军刀)
```

## 第三部分: 建筑概念设计

### 3.1 总统府 (行政中心)

#### 建筑定位
- **功能**: 势力总部，象征权力中心
- **风格**: 中西合璧，庄重威严

#### 设计元素
```
整体布局:
- 坐北朝南，对称布局
- 前院 + 主楼 + 后花园

建筑风格:
- 灰色砖墙主体 (中式)
- 白色罗马柱廊 (西式) - 4根主柱
- 传统中式屋顶 (歇山顶)
- 西式装饰线脚

标志性元素:
- 北洋五色旗 (屋顶旗杆)
- 国徽 (基于十二章国徽简化)
- 入口台阶 (九级，象征九五)

尺寸: 80m x 60m x 25m
```

### 3.2 北洋兵营

#### 建筑定位
- **功能**: 兵营和训练场所
- **风格**: 德式军营，实用主义

#### 设计元素
```
整体布局:
- 四合院式围合
- 中央操练场
- 四周营房

建筑风格:
- 红砖外墙 (德式建筑特色)
- 灰色屋顶 (瓦片)
- 白色窗框 (欧式窗户)
- 拱形门洞

功能区域:
- 士兵宿舍 (通铺)
- 武器库
- 食堂
- 马厩 (骑兵部队)
- 医疗室

尺寸: 100m x 80m x 12m
```

### 3.3 陆军部

#### 建筑定位
- **功能**: 军事指挥和研发
- **风格**: 新古典主义，学术氛围

#### 设计元素
```
建筑风格:
- 灰色花岗岩外墙 (庄重)
- 大型圆柱门廊 (6根立柱)
- 三角形山花 (Pediment)
- 西式屋顶 + 中式屋檐

内部想象:
- 作战室 (大地图、沙盘整)
- 会议室 (长桌、座椅)
- 档案室

尺寸: 70m x 50m x 20m
```

### 3.4 外交部

#### 建筑定位
- **功能**: 外交谈判和国际交往
- **风格**: 欧式洋楼，国际化

#### 设计元素
```
建筑风格:
- 白色外墙 (法式风格)
- 灰色屋顶 (斜坡顶)
- 法式窗户 (落地窗)
- 阳台和栏杆

环境:
- 花园庭院
- 喷泉 (西式)
- 中式假山 (中西结合)

尺寸: 60m x 40m x 18m
```

### 3.5 国会大厦

#### 建筑定位
- **功能**: 政治象征，议会场所
- **风格**: 仿美国国会，民主象征

#### 设计元素
```
建筑风格:
- 白色大理石外墙
- 大型圆顶 (Central Dome)
- 柱廊 (12根立柱，象征十二时辰/月份)
- 台阶和平台

标志性元素:
- 圆顶上的旗杆 (五色旗)
- 入口浮雕 (法律、正义主题)
- 钟楼 (可选)

尺寸: 90m x 70m x 35m
```

### 3.6 北洋军校

#### 建筑定位
- **功能**: 军事教育，培养军官
- **风格**: 中西合璧学堂，学术+军事

#### 设计元素
```
整体布局:
- 教学区 + 操练场 + 宿舍区
- 类似保定军校布局

建筑风格:
- 中西合璧教学楼
- 中式屋顶 + 西式墙体
- 红砖 + 白色装饰线

功能设施:
- 大操场 (阅兵、操练)
- 靶场
- 马厩和骑术训练场
- 学员宿舍 (整齐排列)
- 教室 (黑板、课桌椅)

尺寸: 120m x 100m x 15m
```

## 第四部分: UI设计风格

### 4.1 界面框架

#### 主界面布局
```
┌─────────────────────────────────────┐
│  [势力徽章]  北洋政府               │  ← 顶部栏
├─────────────────────────────────────┤
│                                     │
│         游戏主视窗                  │
│                                     │
├─────────────────────────────────────┤
│ [资源栏]  金币 | 粮食 | 人口         │
├─────────────────────────────────────┤
│ [单位卡] [单位卡] [单位卡] [建筑卡] │  ← 底部控制栏
└─────────────────────────────────────┘
```

#### 色彩应用
- **背景**: 深灰蓝渐变 (#4A5568 → #2D3748)
- **面板**: 半透明黑色 (RGBA: 0,0,0,0.8)
- **边框**: 金色线条 (#D69E2E, 2px)
- **文字**: 象牙白 (#F7FAFC) + 金色高亮

### 4.2 图标设计

#### 单位图标风格
- **形状**: 六边形 (蜂巢状排列)
- **背景**: 深灰色 + 金色边框
- **图案**: 单位剪影 + 势力徽章小标
- **状态**: 血条 (红色渐变) + 经验条 (金色)

#### 建筑图标风格
- **形状**: 圆角矩形
- **背景**: 建筑立面简化图
- **状态**: 建造进度环

### 4.3 势力徽章设计

#### 徽章构成
```
中心: 北洋五色旗 (横向五条)
      红(上) - 黄 - 蓝 - 白 - 黑(下)

环绕: 稻穗花环 (金色)

底部: 交叉步枪 (表示军事)

顶部: 书本展开 (表示教育/文明)

外圈: 金色圆环 + "北洋政府" 字样
```
