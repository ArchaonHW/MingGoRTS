## 2. 北洋政府专属单位详细设计

### 2.1 北洋陆军 (Beiyang Army)

#### 基础信息
- **单位类型**: 精锐步兵
- **历史原型**: 北洋新军正规部队
- **时代背景**: 1912-1928
- **参考照片**: 袁世凯小站练兵、北洋陆军历史照片

#### 外观设计

**制服设计**:
```
上衣:
- 款式: 德式立领军装/中山装混合
- 颜色: 灰蓝色 #6B7280 为主
- 材质: 毛呢布料，中等厚度
- 细节: 
  - 立领，金色领章
  - 胸前口袋2个，斜插
  - 铜质纽扣，刻有北洋标识
  - 肩章显示军衔

裤子:
- 款式: 直筒军裤
- 颜色: 同上衣灰蓝色
- 材质: 毛呢布料
- 细节:
  - 侧面红色条纹装饰
  - 裤脚扎入绑腿

绑腿:
- 颜色: 灰色棉布
- 缠绕方式: 从脚踝到膝盖下方
- 固定: 布质绑带扣

鞋子:
- 款式: 布鞋/皮靴混合
- 颜色: 黑色
- 材质: 皮革鞋底，布质鞋面
```

**头部装备**:
```
帽子:
- 款式: 德式军帽/大檐帽
- 颜色: 同制服灰蓝色
- 细节:
  - 帽檐硬挺，黑色皮质
  - 帽徽: 十二章国徽 (金色)
  - 帽带: 黑色皮质

替代: 冬季毛帽
- 款式: 毛皮护耳帽 (东北部队)
- 颜色: 灰色毛皮
```

**武器装备**:
```
主武器:
- 型号: 汉阳造88式步枪 / 毛瑟Gew98
- 外观: 木质枪身，金属部件
- 细节: 枪身编号，背带

副武器:
- 刺刀: 单刃刺刀，套在枪管上
- 手枪: 驳壳枪 (军官配备)

装备:
- 背包: 帆布背包，棕色
- 弹药袋: 胸前交叉式，皮革
- 水壶: 铝制，帆布套
- 刺刀鞘: 皮革，挂于腰间
```

**面部特征**:
```
年龄: 25-35岁青壮年
面容: 东方男性面孔
表情: 严肃、训练有素
发型: 短发，部分光头
胡须: 部分留八字胡 (模仿军官风格)
```

#### 动画需求

**基础动画**:
1. **Idle_A** (待机_站立): 持枪站立，警戒姿态
2. **Idle_B** (待机_休息): 枪靠肩，休息姿态
3. **Walk** (行走): 行军步伐，持枪前进
4. **Run** (跑步): 冲锋姿态，快速移动
5. **Attack_Melee** (近战攻击): 刺刀突刺
6. **Attack_Ranged** (远程攻击): 举枪瞄准射击
7. **Reload** (装填): 拉栓装填动作
8. **Death_A** (死亡_前扑): 向前扑倒
9. **Death_B** (死亡_后仰): 向后倒地
10. **Hit** (受击): 被击中踉跄

**特殊动画**:
- **Formation** (列队): 整队动画
- **Salute** (敬礼): 向军官敬礼
- **Cheer** (欢呼): 胜利欢呼

### 2.2 北洋骑兵 (Beiyang Cavalry)

#### 基础信息
- **单位类型**: 重型骑兵
- **历史原型**: 北洋骑兵部队
- **特点**: 装备近代武器的骑兵

#### 外观设计

**骑兵制服**:
```
上衣:
- 款式: 短款骑兵夹克
- 颜色: 灰蓝色 #6B7280
- 材质: 厚实毛呢，耐磨
- 细节:
  - 短款设计，方便骑马
  - 高领，防风
  - 胸前斜跨弹药带
  - 袖口收紧设计

裤子:
- 款式: 马裤，大腿宽松，小腿收紧
- 颜色: 同上衣
- 材质: 厚实毛呢
- 细节: 臀部加固，内侧皮革防磨

马靴:
- 款式: 高筒马靴
- 颜色: 黑色皮革
- 细节:
  - 及膝高度
  - 马刺 (金属)
  - 硬质鞋底，带跟
```

**头部装备**:
```
头盔:
- 款式: 皮质头盔/布质军帽
- 颜色: 同制服灰蓝色
- 细节: 
  - 护耳设计 (冬季)
  - 帽徽: 北洋骑兵标识
  - 系带固定
```

**武器装备**:
```
主武器:
- 骑兵步枪: 缩短版步枪，马背上使用
- 马刀: 军刀，弧形刀刃
- 位置: 步枪背于背后，马刀挂于腰侧

装备:
- 马鞍: 军鞍，皮质
- 马具: 缰绳、马镫
-  saddle bags: 马鞍包
```

**马匹设计**:
```
品种: 蒙古马/混血马
颜色: 棕色、黑色、白色
马具: 军绿色马具，皮质
装饰: 简单实用，无过多装饰
```

#### 动画需求

**骑兵基础动画**:
1. **Horse_Idle** (马匹待机): 马匹原地踏步、甩尾
2. **Horse_Walk** (马匹行走): 慢步走
3. **Horse_Run** (马匹奔跑):  gallop
4. **Horse_Turn** (马匹转向): 左右转向
5. **Mounted_Idle** (骑乘待机): 马上坐姿
6. **Mounted_Attack_Sword** (马刀攻击): 挥砍动作
7. **Mounted_Attack_Rifle** (骑射): 马上射击
8. **Mounted_Hit** (骑乘受击): 马上踉跄
9. **Dismount_Start** (下马开始): 准备下马
10. **Dismount_End** (下马完成): 地面站立
11. **Mount_Start** (上马开始): 准备上马
12. **Mount_End** (上马完成): 骑乘姿态

## 7. 通用模型制作规范

### 7.1 建模流程

```
1. 概念设计 (Concept)
   - 参考收集
   - 草图绘制
   - 设计确认

2. 高模制作 (High Poly)
   - ZBrush雕刻
   - 细节刻画
   - 服装褶皱

3. 低模制作 (Low Poly)
   - 拓扑优化
   - UV展开
   - LOD制作

4. 材质贴图 (Texturing)
   - Substance Painter
   - PBR材质
   - 细节绘制

5. 骨骼绑定 (Rigging)
   - 骨骼架设
   - 权重绘制
   - 控制器设置

6. 动画制作 (Animation)
   - 基础动画
   - 特殊动画
   - 动画测试

7. 引擎导入 (Engine)
   - FBX导出
   - 材质调整
   - 性能测试
```

### 7.2 命名规范

**模型命名**:
```
格式: [势力缩写]_[单位类型]_[版本]_[LOD]

示例:
- BA_Army_Soldier_v01_LOD0.fbx  (北洋陆军LOD0)
- BA_Army_Soldier_v01_LOD1.fbx  (北洋陆军LOD1)
- BA_Cavalry_Mount_v01_LOD0.fbx (北洋骑兵坐骑)
- GM_Army_Cadet_v01_LOD0.fbx    (黄埔学生军)
- CP_Guerrilla_v01_LOD0.fbx     (红军游击队)
```

**贴图命名**:
```
格式: [势力缩写]_[部位]_[类型]_[分辨率]

示例:
- BA_Uniform_D_2K.png    (北洋制服Diffuse)
- BA_Uniform_N_2K.png    (北洋制服Normal)
- BA_Head_D_1K.png       (北洋头部Diffuse)
- GM_Weapon_D_1K.png     (国民武器Diffuse)
```

**动画命名**:
```
格式: [势力缩写]_[单位]_[动画类型]_[变体]

示例:
- BA_Army_Idle_A
- BA_Army_Walk
- BA_Army_Attack_Melee
- BA_Cavalry_Mounted_Run
```

### 7.3 技术规范

**文件格式**:
- 模型: FBX (2016版本)
- 贴图: PNG (带透明), TGA (引擎)
- 动画: FBX (嵌入或分离)

**坐标系**:
- 朝向: Y轴向上, Z轴向前
- 单位: 厘米 (cm)
- 比例: 1单位 = 1cm

**优化要求**:
- 骨骼数量: 最大64根
- 蒙皮权重: 每顶点最多4个权重
- 材质数量: 每模型最多3个材质
- 贴图尺寸: 2的幂次方
