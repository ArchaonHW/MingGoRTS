# Epic 6.1 北洋政府美术资产实施指南

## 概述

**任务ID**: Epic 6.1  
**目标**: 制作北洋政府势力的完整美术资产包  
**预估工期**: 25工作日 (约5周)  
**产出物**: 4个单位模型 + 6座建筑 + 1套UI套件

---

## 资产清单

### 1. 专属单位 (4个)

#### 1.1 北洋步兵 (Beiyang Infantry)
- **模型规格**: 
  - 面数: 8,000-12,000 tris (LOD0)
  - 贴图: 4K PBR (Albedo/Normal/Metallic/Roughness/AO)
  - 骨骼: 32根骨骼，支持RTS动画系统
  
- **视觉特征**:
  - 灰蓝色制服 (RGB: 70, 80, 95)
  - 德式军帽 (M1907式)
  - 毛瑟步枪 (Gewehr 98)
  - 皮革绑腿和布鞋
  
- **动画需求**:
  - Idle (3种变体)
  - Walk/Run
  - Attack (刺刀冲锋)
  - Death
  - Victory

#### 1.2 北洋骑兵 (Beiyang Cavalry)
- **模型规格**:
  - 面数: 12,000-16,000 tris (含战马)
  - 贴图: 4K PBR
  - 骨骼: 48根骨骼 (骑手24 + 马24)

- **视觉特征**:
  - 灰蓝色骑兵制服
  - 马刀 (传统中式马刀)
  - 蒙古马/三河马品种
  - 皮质马鞍和缰绳

- **动画需求**:
  - Horse Idle/Walk/Run
  - Mounted Attack
  - Dismount/Mount

#### 1.3 北洋炮兵 (Beiyang Artillery)
- **模型规格**:
  - 面数: 10,000-14,000 tris
  - 贴图: 4K PBR
  - 骨骼: 36根骨骼

- **视觉特征**:
  - 加厚的灰蓝色制服
  - 德式钢盔原型
  - 75mm克虏伯野战炮
  - 弹药箱和工具

- **动画需求**:
  - Artillery Setup
  - Loading/Firing
  - Limber/Unlimber

#### 1.4 北洋军官 (Beiyang Officer)
- **模型规格**:
  - 面数: 10,000-14,000 tris
  - 贴图: 4K PBR
  - 骨骼: 32根骨骼

- **视觉特征**:
  - 深灰色礼服制服
  - 金色肩章和领章
  - 毛瑟C96手枪
  - 皮质公文包/望远镜

- **动画需求**:

## 技术规格

### 3D模型标准
```
命名规范: BY_[Type]_[Name]_[Version]
示例: BY_Unit_Infantry_v01.fbx

LOD层级:
- LOD0: 原始面数 (0-10m)
- LOD1: 50%面数 (10-30m)
- LOD2: 25%面数 (30-100m)
- LOD3: 10%面数 (100m+)

碰撞体: 简化包围盒
- 单位: 胶囊体 (半径0.5m, 高1.8m)
- 建筑: 凸包或盒体
```

### 材质标准
```
PBR工作流程: Metallic-Roughness
贴图命名: [AssetName]_[MapType]
- _Albedo (RGB)
- _Normal (RGB)
- _Metallic (R)
- _Roughness (G)
- _AO (B)
- _Emissive (RGB, 可选)

材质实例命名: M_[Faction]_[Type]_[Name]
示例: M_BY_Unit_Infantry_Uniform
```

### 骨骼标准
```
骨骼命名: 使用UE4人体骨骼命名规范
Root -> Pelvis -> Spine -> ...

RTS动画兼容:
- 上半身: Yaw/Pitch自由 (瞄准)
- 下半身: 独立行走循环
- 武器: 插槽系统 (Socket)
```

## 历史参考

### 服饰参考
- **北洋军服**: 参考1912-1928年间北洋陆军制服
- **颜色**: 德式灰蓝 (Feldgrau变种)
- **装备**: 参考一战时期德军装备改编

### 建筑参考
- **总统府**: 参考北京中南海怀仁堂、南京总统府
- **兵营**: 参考保定军校、天津武备学堂
- **风格**: 1910年代中西合璧建筑风格

### 纹章参考
- **五色旗**: 红、黄、蓝、白、黑代表五族共和
- **徽章样式**: 参考北洋政府时期的军徽和印章

## 验收标准

### 3D模型
- [ ] 面数符合LOD规范
- [ ] UV展开无重叠，利用率>80%
- [ ] 法线方向正确
- [ ] 骨骼绑定正确，权重平滑
- [ ] 在引擎中测试无误

### 贴图材质
- [ ] 分辨率符合规格
- [ ] PBR参数正确 (Metallic/Roughness)
- [ ] 无明显接缝
- [ ] 色彩风格统一

### 动画
- [ ] 动作流畅自然
- [ ] 无骨骼穿插
- [ ] 循环动画无缝衔接
- [ ] 与RTS系统兼容

### UI
- [ ] 分辨率适配多屏幕
- [ ] 风格与势力主题一致
- [ ] 可读性良好
- [ ] 按钮状态完整
