# Epic 6.4.1 军阀势力美术概念设计 (七大军阀)

## 设计目标

为七大传统军阀势力（奉系、直系、皖系、晋系、桂系、滇系、川系）创建各具地域特色、历史真实、风格鲜明的视觉设计。

**工期**: 10工作日 (每个势力约1.5天)  
**产出**: 7份风格指南 + 共享元素库

---

## 一、奉系军阀 (东北/张作霖)

### 1.1 视觉特征

#### 色彩系统
- **主色**: 深绿色 #1B5E20 (东北森林)
- **辅色**: 土黄色 #8D6E63 (东北土地)
- **点缀**: 金色 #FFD700 (满洲贵族遗风)

#### 核心风格
- 东北汉子彪悍风格
- 日俄影响混杂
- 骑兵传统
- 土匪出身但正规化

### 1.2 单位设计

#### 东北步兵
```
头部: 狗皮帽子 (东北特色) 或 大盖帽
上身: 深绿色厚棉衣 (东北寒冷)
下身: 棉裤 + 绑腿
装备: 汉阳造/日制步枪、大刀
特色: 烟袋、酒壶
```

#### 东北骑兵
```
骑手: 绿色骑兵制服
马匹: 蒙古马、三河马
装备: 马刀、步枪
特色: 东北汉子魁梧身材
```

### 1.3 建筑设计

#### 奉天督军府
- 东北传统官署建筑
- 日式建筑影响
- 红砖外墙
- 高墙大院

### 1.4 特色元素
- 张作霖形象参考
- 东北虎标识
- 龙纹装饰 (奉系自认正统)

## 共享元素库

### 通用军阀元素
```
军帽: 各式军帽，各有特色
制服: 北洋灰、地方色、缴获日军装备
武器: 汉阳造、土制武器、缴获装备
交通工具: 马匹、轿子、老式汽车
```

### 建筑共享风格
```
督军府: 各地官署建筑，中西合璧
兵营: 简易营房，地方特色
城墙: 部分军阀有城墙防御
```

### UI差异化设计
每个军阀势力应有独特的UI色调，但保持整体一致性:
- 奉系: 深绿色系
- 直系: 灰蓝色系
- 皖系: 褐色系
- 晋系: 土黄色系
- 桂系: 深绿色系
- 滇系: 藏青色系
- 川系: 灰色系
