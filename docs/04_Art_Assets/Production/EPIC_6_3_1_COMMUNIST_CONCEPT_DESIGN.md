# Epic 6.3.1 共产党美术概念设计

## 设计目标

为中国共产党势力创建工农红军特色、游击战风格、人民战争主题的视觉风格，体现其草根性和革命韧性。

**工期**: 5工作日  
**产出**: 风格指南PDF + 概念草图集 + 参考图库

---

## 第一部分: 视觉风格指南

### 1.1 色彩系统

#### 主色调
| 颜色 | 色值 | 用途 | 历史依据 |
|------|------|------|----------|
| **革命红** | #C62828 | 旗帜/徽章/装饰主色 | 中国共产党党旗 |
| **军绿** | #2E7D32 | 制服主色 | 红军军装 |
| **土黄** | #8D6E63 | 装备/建筑 | 根据地特色 |
| **红星金** | #FFD700 | 红星/徽章 | 红军五角星 |
| **灰蓝** | #546E7A | 灰色制服 (早期) | 北伐军遗留下来的服装 |

#### 色彩比例
```
主色 (50%): 军绿 / 革命红
辅色 (35%): 土黄 / 灰蓝
点缀 (15%): 红星金 / 白色
```

### 1.2 视觉特征关键词

#### 核心风格
- **工农本色**: 来自人民，服务人民
- **游击战术**: 灵活机动，以弱胜强
- **革命理想**: 坚定的信念，红色精神
- **艰苦朴素**: 资源匮乏但意志坚定

#### 设计语言
- 粗糙但坚韧的质感
- 红五星元素无处不在
- 土布、草鞋、绑腿
- 简陋但实用的装备

## 第二部分: 单位概念设计

### 2.1 红军步兵 (Red Army Infantry)

#### 角色设定
- **身份**: 中国工农红军普通战士
- **时期**: 1927-1937年 (长征时期)
- **特点**: 来自农民，政治觉悟高

#### 视觉元素
```
头部:
- 八角帽 (红军标志性军帽)
- 红五星帽徽
- 或草帽/斗笠 (南方根据地)

上身:
- 灰蓝色制服 (早期) 或 土黄色/军绿色 (后期)
- 红领章 (识别标志)
- 红袖章 (革命者)
- 粗布材质

下身:
- 绑腿 (灰色或蓝色布料)
- 草鞋 (稻草编织)
- 或布鞋

装备:
- 汉阳造步枪
- 大刀 (红缨刀)
- 手榴弹
- 米袋和干粮袋
```

### 2.2 游击队 (Guerrilla Fighter)

#### 角色设定
- **身份**: 地方游击队战士
- **特点**: 就地取材，灵活机动

#### 视觉元素
```
头部:
- 普通农民草帽
- 毛巾包头 (北方)
- 或光头/短发

上身:
- 平民服装 + 红袖章
- 便装为主
- 马甲或坎肩

装备:
- 土制武器 (大刀、长矛)
- 缴获的步枪
- 猎枪/鸟铳
- 土地雷
```

### 2.3 红军骑兵 (Red Cavalry)

#### 角色设定
- **身份**: 红军骑兵部队
- **特点**: 机动性强，快速突袭

#### 视觉元素
```
骑手:
- 标准红军制服
- 马刀挂于腰侧
- 马鞍包

马匹:
- 蒙古马/川马
- 简易皮质马鞍
- 红军标识 (红布)

装备:
- 中式马刀
- 步枪 (马枪)
```

### 2.4 机枪手 (Machine Gunner)

#### 角色设定
- **身份**: 重武器操作手
- **特点**: 火力支援核心

#### 视觉元素
```
头部:
- 八角帽
- 或布质头盔

上身:
- 厚重工作服
- 弹药带 (大量子弹)
- 肩扛枪架部件

装备:
- 捷克式ZB26轻机枪
- 或马克沁重机枪
- 备用枪管
```

### 2.5 红军女战士 (Female Red Army Soldier)

#### 角色设定
- **身份**: 红军中的女性战士
- **特点**: 巾帼不让须眉

#### 视觉元素
```
头部:
- 剪短发或辫子
- 八角帽

上身:
- 改良版军服 (更合身)
- 红领章
- 绑腿

装备:
- 步枪或手枪
- 医疗包 (卫生员)
- 宣传材料 (宣传员)
```

## 第三部分: 建筑概念设计

### 3.1 瑞金中央苏区政府 (Ruijin Soviet Government)

#### 建筑定位
- **功能**: 中央苏区行政中心
- **风格**: 乡村政府建筑，朴素实用

#### 设计元素
```
建筑风格:
- 赣南客家建筑风格
- 土木结构
- 红色旗帜和标语
- 简易广场

标志性元素:
- 苏维埃政府牌匾
- 马克思列宁画像
- 红色五角星
- 革命标语墙
```

### 3.2 延安窑洞 (Yan'an Cave Dwellings)

#### 建筑定位
- **功能**: 根据地指挥中心
- **风格**: 陕北窑洞，革命圣地

#### 设计元素
```
建筑风格:
- 黄土高原窑洞
- 依山而建
- 土黄色主调
- 简朴的门窗

标志性元素:
- 杨家岭/枣园风格
- 毛主席旧居
- 中央大礼堂
- 革命时期的马灯
```

### 3.3 红军兵工厂 (Red Army Arsenal)

#### 建筑定位
- **功能**: 武器修理和制造
- **风格**: 简易工业，自力更生

#### 设计元素
```
建筑风格:
- 山洞兵工厂 (隐蔽)
- 简易厂房
- 土法上马

生产设施:
- 修理枪械
- 制造手榴弹
- 复装子弹
- 大刀长矛作坊
```

### 3.4 根据地民居 (Soviet Base Residents)

#### 建筑定位
- **功能**: 民众支持和兵源补充
- **风格**: 各地民居风格

#### 设计元素
```
南方风格:
- 赣南客家围屋
- 湖南湘西吊脚楼
- 福建土楼

北方风格:
- 陕北窑洞
- 山西四合院

标识:
- 红色标语
- 支援红军的旗帜
- 儿童团站岗
```

### 3.5 红军医院 (Red Army Hospital)

#### 建筑定位
- **功能**: 伤员救治
- **风格**: 战地医疗，条件艰苦

#### 设计元素
```
建筑风格:
- 寺庙/祠堂改建
- 简易棚屋
- 山洞医院

设施:
- 简陋病床
- 中药和西药混用
- 手术台
- 绷带和药材
```
