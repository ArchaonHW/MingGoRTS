# Epic 7 音效音乐实施总指南

## 概述

**目标**: 为12个势力创建完整的音频资产体系，包括特色音乐、单位音效、环境音效  
**适用范围**: 背景音乐、战斗音效、UI音效、环境音效、语音旁白  
**制作周期**: 约4-6个月  
**团队配置**: 建议4-6人音频团队 (作曲、音效设计、技术音频、配音)

---

## 第一部分: 音频系统架构

### 1.1 音频分层结构

```
Layer 1: 背景音乐 (Music)
  ├─ 势力主题音乐 (12套)
  ├─ 情境音乐 (战斗/和平/紧张/胜利/失败)
  ├─ 地图音乐 (10个地区)
  └─ 特殊事件音乐

Layer 2: 战斗音效 (Combat SFX)
  ├─ 武器音效 (枪械/冷兵器/爆炸)
  ├─ 单位语音 (12势力 x 4单位)
  ├─ 环境战斗音效
  └─ 特效音效

Layer 3: 环境音效 (Ambient)
  ├─ 地图环境 (10个地区特色)
  ├─ 建筑环境
  ├─ 天气系统
  └─ 野生动物

Layer 4: UI音效 (Interface)
  ├─ 交互音效 (点击/悬停/确认)
  ├─ 通知音效 (警告/成功/失败)
  ├─ 势力特色UI音
  └─ 菜单过渡音效
```

### 1.2 技术规格

#### 音频格式标准
| 类型 | 格式 | 采样率 | 位深 | 压缩 |
|------|------|--------|------|------|
| 背景音乐 | .ogg/.wav | 48kHz | 16-bit | Vorbis Q5 |
| 音效 | .wav/.ogg | 48kHz | 16-bit | Vorbis Q4 |
| UI音效 | .wav | 48kHz | 16-bit | 不压缩 |
| 语音 | .ogg | 48kHz | 16-bit | Vorbis Q6 |

#### 音量标准
```
背景音乐: -12 dBFS (主音量)
战斗音效: -6 dBFS (峰值)
环境音效: -18 dBFS (平均)
UI音效: -10 dBFS
语音: -8 dBFS

动态范围: 建议保持12-16dB
```

#### 3D音频设置
```
衰减模型: 对数距离
最大距离: 5000 units
参考距离: 100 units
衰减系数: 1.0
空间化: 启用HRTF
```

### 2.2 音乐曲目清单 (每势力)

```
势力主题曲 x1 (3-4分钟)
  └─ 主菜单播放
  └─ 势力选择界面

战斗音乐 x3
  ├─ 战斗开始 (30s, 紧张 buildup)
  ├─ 战斗进行 (2-3min, 可循环)
  └─ 战斗高潮 (1min, 激烈)

和平音乐 x2
  ├─ 基地建设 (2min, 舒缓)
  └─ 资源采集 (2min, 轻快)

胜利/失败音乐 x2
  ├─ 胜利 (30s, 史诗)
  └─ 失败 (20s, 悲壮)

合计: 每势力8首曲目
总计: 12势力 × 8首 = 96首曲目
```

### 2.3 动态音乐系统

#### 音乐状态切换
```cpp
// 音乐层级混合
enum class EMusicLayer
{
    Ambient,    // 基础层 - 始终播放
    Tension,    // 紧张层 - 敌人接近时渐入
    Combat,     // 战斗层 - 交战时激活
    Victory     // 胜利层 - 胜利时播放
};

// 过渡参数
TransitionTime: 2-4 seconds
CrossfadeCurve: S-curve (平滑)
StingerOverlap: 允许0.5s重叠
```

#### 垂直重混 (Vertical Remixing)
```
轨道1: 基础旋律 (始终)
轨道2: 节奏加强 (紧张时)
轨道3: 铜管加入 (战斗时)
轨道4: 合唱/史诗 (高潮时)

通过MIDI或音频stem控制各轨道音量
```

## 第六部分: 制作流程与规范

### 6.1 音频制作流程

```
阶段1: 概念设计 (2-3天/势力)
  ├─ 确定音乐风格方向
  ├─ 收集参考音乐
  ├─ 编写音效设计文档
  └─ 制定录制计划

阶段2: 音乐创作 (5-7天/势力)
  ├─ 主题旋律创作
  ├─ 各情境曲目编排
  ├─ 乐器录制/MIDI制作
  ├─ 混音初版
  └─ 内部审核

阶段3: 音效制作 (4-5天/势力)
  ├─ 拟音 (Foley)录制
  ├─ 音效库素材处理
  ├─ 合成音效设计
  └─ 分类整理

阶段4: 语音录制 (3-4天/势力)
  ├─ 演员选角
  ├─ 台词排练
  ├─ 正式录制
  ├─ 后期处理
  └─ 审核验收

阶段5: 技术集成 (2-3天/势力)
  ├─ UE5音频导入
  ├─ SoundCue设置
  ├─ 3D空间化配置
  ├─ 混音测试
  └─ 性能优化

阶段6: 迭代优化 (持续)
  ├─ 游戏内测试
  ├─ 平衡调整
  ├─ Bug修复
  └─ 最终验收
```

### 6.2 命名规范

```
音乐: Music_[Faction]_[Type]_[Name]
  例: Music_BY_Theme_MainMenu

音效: SFX_[Category]_[Faction]_[Name]
  例: SFX_Combat_BY_RifleShot

语音: VO_[Faction]_[Unit]_[Action]_[Index]
  例: VO_BY_Infantry_Move_01

环境: Amb_[Region]_[Type]
  例: Amb_NorthChina_Wind

UI: UI_[Faction]_[Action]
  例: UI_BY_ButtonClick
```

```

- 限制同时播放音源数 (32个)

存储优化:
```
