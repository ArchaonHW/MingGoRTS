## 🎮 使用示例

### 基本保存操作
```cpp
// 保存遊戲狀態
TMap<FString, FString> GameState;
GameState.Add(TEXT("Level"), TEXT("Level1"));
GameState.Add(TEXT("Score"), TEXT("1000"));

TArray<uint8> StateData = SaveLoadSystem->SerializeData(GameState, ESaveFormat::Binary);
FString SaveID = SaveLoadSystem->SaveGameData(TEXT("QuickSave"), ESaveDataType::GameState, StateData);

// 保存到槽位
SaveLoadSystem->SaveToSlot(TEXT("Slot1"), TEXT("Main Game Save"));
```

### 載入操作
```cpp
// 從槽位載入
bool bSuccess = SaveLoadSystem->LoadFromSlot(TEXT("Slot1"));

// 載入特定數據
TArray<uint8> LoadedData;
if (SaveLoadSystem->LoadGameData(SaveID, LoadedData))
{
    TMap<FString, FString> GameState = SaveLoadSystem->DeserializeData(LoadedData, ESaveFormat::Binary);
}
```

### 高級功能
```cpp
// 自動保存
SaveLoadSystem->SetAutoSaveInterval(300.0f); // 5分鐘

// 數據壓縮
SaveLoadSystem->CompressSaveData(SaveID);

// 數據加密
SaveLoadSystem->EncryptSaveData(SaveID, TEXT("SecretKey"));

// 備份數據
SaveLoadSystem->BackupSaveData(SaveID, TEXT("Backup/"));
```
