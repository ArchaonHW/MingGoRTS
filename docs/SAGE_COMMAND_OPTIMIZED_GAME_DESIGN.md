# 至聖者指揮學優化遊戲設計方案

## 概述

本設計方案將「至聖者指揮學」系統的核心哲學整合進入 MingGoRTS 的 12 勢力設計中，創造獨特的戰略指揮體驗。

---

## 核心設計理念

### 三層指揮架構融入勢力設計

```
┌─────────────────────────────────────────────────────────────┐
│  MingGoRTS 指揮哲學層 (Sage Command Philosophy Layer)      │
├─────────────────────────────────────────────────────────────┤
│  角色類型系統    三權指揮系統    正逆六策系統    防墮機制    │
│  ├─聖者          ├─道權(監測)   ├─立國(正)     ├─三大徵象   │
│  ├─魔王          ├─策權(切換)   ├─破局(逆)     ├─贖罪機制   │
│  └─偽聖者        └─兵權(執行)   └─不破人(逆)   └─最高戒律   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  勢力應用層 (Faction Application Layer)                      │
├─────────────────────────────────────────────────────────────┤
│  12勢力各自擁有獨特的指揮哲學傾向與專屬策略組合              │
└─────────────────────────────────────────────────────────────┘
```

## 勢力專屬機制重設計

### 1. 北洋政府 (偽聖者型)

#### 核心機制：正統性偽裝 (Legitimacy Facade)

**機制說明：**
北洋政府作為中央正統，表面使用正策維護秩序，暗地裡卻頻繁使用逆策。

**專屬特性：**
- **正統光環**：使用正策時效果 +30%，但獲得「偽正統」標記
- **暗度陳倉**：可在使用正策後的 3 回合內無懲罰使用逆策
- **暴露風險**：連續使用逆策超過 3 次後，「偽正統」標記暴露，正策效果 -50%
- **日本勾結**：與日本勢力合作時，逆策效果 +40%，但墮落值翻倍

**專屬策略：**
- **正策**：立制 (維護中央權威) + 立人 (拉攏地方實力派)
- **逆策**：破結構 (瓦解反對派系) + 不破人 (暗控議會議員)

**墮落閾值**：80 (較低，因為是偽聖者)

---

### 2. 国民政府 (聖者型)

#### 核心機制：正逆平衡 (Righteous-Evil Balance)

**機制說明：**
國民政府作為革命正統，能夠在正逆策略間靈活切換而不受懲罰。

**專屬特性：**
- **三民主義**：正策效果 +25%，切換至逆策時無墮落值懲罰
- **北伐精神**：軍隊士氣在正逆切換後 +20%
- **黃埔傳統**：將領培養速度 +50%，且將領不受單一策略限制
- **正統優勢**：其他勢力對國民政府使用逆策時，效果 -30%

**專屬策略：**
- **正策**：立國 (建立國民政府正統) + 立制 (推行現代化改革)
- **逆策**：破局 (北伐統一戰爭) - 視為正義之戰，墮落值減半

**墮落閾值**：150 (標準聖者)

---

### 3. 中国共产党 (聖者型)

#### 核心機制：人民戰爭 (People's War Doctrine)

**機制說明：**
中共以正策為核心，依靠人民支持，逆策僅在極端情況下使用。

**專屬特性：**
- **群眾基礎**：立人策略效果翻倍，徵兵效率 +100%
- **游擊戰術**：在不利地形使用正策時，效果不打折
- **統一戰線**：與其他勢力結盟時，雙方正策效果 +20%
- **思想改造**：俘虜的敵軍單位可轉化為己方單位 (立人策略延伸)

**專屬策略：**
- **正策**：立人 (發動群眾) + 立制 (建立根據地)
- **逆策**：破局 (游擊戰突襲) - 在敵後使用時不產生墮落值

**墮落閾值**：150 (聖者標準)

**特殊規則**：
- 中共在發動「人民戰爭」時，所有策略視為正策，不產生墮落值
- 但若連續 5 回合未發動群眾，則進入「脫離群眾」狀態，正策效果 -50%

---

### 4. 奉系军阀 (魔王型)

#### 核心機制：東北虎王 (Tiger of the Northeast)

**機制說明：**
奉系軍閥以武力為尊，頻繁使用逆策，無法停止。

**專屬特性：**
- **無法無天**：逆策效果 +60%，但無法連續 3 回合不使用逆策
- **虎狼之師**：軍隊攻擊力 +25%，但忠誠度基礎值較低
- **日本依賴**：接受日本援助時，逆策效果再 +20%，但會累積「漢奸」標記
- **暴虐統治**：佔領地區的資源產出 +30%，但穩定性 -40%

**專屬策略：**
- **正策**：幾乎不使用，效果僅為正常的 50%
- **逆策**：全逆策精通，尤其是破局 (武力統一) 和破結構 (瓦解敵軍)

**墮落閾值**：200 (魔王高閾值)

**特殊規則**：
- 奉系一旦開始使用逆策，必須連續使用至少 3 回合
- 若強行停止，將觸發「軍隊譁變」事件

---

### 5. 直系军阀 (魔王型)

#### 核心機制：中原霸主 (Central Plains Hegemon)

**機制說明：**

**專屬特性：**

- **速戰速決**：逆策冷卻時間 -30%，鼓勵頻繁使用
- **吳佩孚軍略**：使用破局策略時，可同時攻擊多個目標
- **兵多將廣**：將領數量 +3，但平均質量較低

**專屬策略：**
- **正策**：立國 (建立直系霸權) - 實際效果類似逆策
- **逆策**：破局 (直奉戰爭) + 破結構 (瓦解皖系)

**墮落閾值**：200

## 系統整合實現

### 代碼架構調整

```
Source/MingGoRTS/Public/Factions/
├── MingFactionSageProfile.h          # 勢力指揮學屬性
├── MingFactionStrategySet.h          # 勢力專屬策略組
├── MingFactionMoralAlignment.h       # 勢力道德傾向
└── MingFactionWuXingAffinity.h       # 勢力五行偏好

Source/MingGoRTS/Private/Factions/
└── FactionSageCommandIntegration.cpp # 勢力與指揮學整合
```

### 關鍵整合點

1. **勢力選擇時確定角色類型**
   ```cpp
   // 玩家選擇勢力時，自動設定其指揮學角色類型
   void UFactionSelectionWidget::OnFactionSelected(EFactionType Faction)
   {
       ESageCharacterType CharacterType = GetFactionDefaultCharacterType(Faction);
       SageCommandSystem->SetCharacterType(CharacterType);
   }
   ```

2. **策略使用時檢查勢力修正**
   ```cpp
   // 使用策略時，應用勢力專屬修正
   float UFactionStrategyModifier::ModifyStrategyEffect(
       EFactionType Faction, 
       ESixStrategyType Strategy, 
       float BaseEffect)
   {
       float FactionMultiplier = GetFactionStrategyMultiplier(Faction, Strategy);
       return BaseEffect * FactionMultiplier;
   }
   ```

3. **五行節奏與勢力事件**
   ```cpp
   // 五行階段轉換時，觸發勢力專屬事件
   void UFactionWuXingEventSystem::OnWuXingPhaseChanged(EWuXingPhase NewPhase)
   {
       for (auto& Faction : ActiveFactions)
       {
           if (IsFactionFavorablePhase(Faction, NewPhase))
           {
               TriggerFactionAdvantageEvent(Faction, NewPhase);
           }
       }
   }
   ```
