# MingGoRTS 並行開發排程與風險應對計畫

## 一、專案概況

- **總任務數**：467個
- **總工時**：930小時（含15%緩衝 = 1,070小時）
- **開發週期**：12週（壓縮至10週並行開發）
- **優先級分佈**：高(70%)、中(25%)、低(5%)

## 三、風險應對預案

### 高風險項目矩陣

| 風險ID | 風險描述 | 概率 | 影響 | 應對策略 | 負責人 |
|--------|----------|------|------|----------|--------|
| R01 | 編譯錯誤修復超時 | 40% | 高 | 提前啟動，每日同步 | Dev-A |
| R02 | 三權系統依賴衝突 | 30% | 中 | 接口先行，mock數據 | Dev-C |
| R03 | AI適配複雜度超標 | 50% | 高 | 簡化AI，MVP先行 | Dev-C |
| R04 | 五行節奏數值不平衡 | 35% | 中 | 預設調整工具，快速迭代 | Dev-B |
| R05 | 防墮機制檢測失效 | 25% | 高 | 多層檢測，降級機制 | Dev-A |
| R06 | UE5版本兼容性問題 | 20% | 高 | 鎖定版本，預留緩衝 | Dev-D |

### 具體應對措施

#### R01: 編譯錯誤修復超時

**觸發條件**：第2週結束仍有>100個錯誤

**應對方案**：
1. 啟動「錯誤凍結」機制：暫時註釋非核心錯誤代碼
2. 引入外部支援：調配其他項目C++專家
3. 調整排程：壓縮Phase 2工期，確保基礎可用

**降級方案**：
- 優先保證核心系統編譯通過
- 非核心功能（AI特效）可延後

#### R02: 三權系統依賴衝突

**觸發條件**：道權/策權/兵權接口定義衝突

**應對方案**：
1. 建立「權力中台」：統一權力管理接口
2. 使用Adapter模式：允許各權系統獨立演化
3. 每日接口同步會議（15分鐘）

**技術方案**：
```cpp
// 權力中台接口
class ICommandAuthority {
    virtual bool CanExecute(EAuthorityType Type) = 0;
    virtual void RegisterAuthority(EAuthorityType Type, TSharedPtr<IAuthority> Authority) = 0;
};
```

#### R03: AI適配複雜度超標

**觸發條件**：第8週AI基礎框架未完成

**應對方案**：
1. **MVP策略**：先實現規則基礎AI，再行為樹後續迭代
2. **分級AI**：
   - L1: 基礎反應AI（必須完成）
   - L2: 策略型AI（可延後）
   - L3: 學習型AI（後續版本）
3. 使用Unreal内置AI框架（AIController、BehaviorTree）

#### R04: 五行節奏數值不平衡

**觸發條件**：測試階段發現某元素過強/過弱

**應對方案**：
1. 建立「數值熱更新」系統：無需重啟調整
2. 預設平衡公式：
   ```
   效果強度 = 基礎值 × (1 + 相生加成 - 相剋減弱)
   ```
3. A/B測試機制：並行運行多組數值方案

#### R05: 防墮機制檢測失效

**觸發條件**：無法準確檢測玩家/AI墮落行為

**應對方案**：
1. **多維檢測**：
   - 行為檢測（資源獲取方式）
   - 策略檢測（選擇逆策頻率）
   - 結果檢測（遊戲結局影響）
2. **閾值動態調整**：根據遊戲階段調整敏感度
3. **人工覆核機制**：重要判定提供人工確認接口

#### R06: UE5版本兼容性問題

**觸發條件**：GitHub Action編譯失敗，本地/服務器環境差異

**應對方案**：
1. 鎖定UE5.3.2版本，禁止自動更新
2. 使用Docker容器統一編譯環境
3. 建立「編譯環境文檔」：詳細記錄所有依賴版本

## 七、附錄：緊急情況處理流程

### P0級緊急情況（專案停滯）

**觸發條件**：
- 核心系統編譯失敗超過3天
- 關鍵人員離職
- UE5重大版本變更不兼容

**處理流程**：
1. 立即啟動「戰情室」：全員會議，2小時內決策
2. 評估影響範圍：使用影響矩陣分析
3. 制定應對方案：調整範圍/延期/增加資源
4. 24小時內執行：快速行動，每日同步

### P1級問題（階段受阻）

**觸發條件**：
- 單一Phase延期超過2天
- 關鍵功能無法實現
- 多人阻塞同一問題

**處理流程**：
1. 問題上報：Dev-A評估影響
2. 方案制定：24小時內提供3個可選方案
3. 決策執行：選擇最優方案，調整排程
