## 🎮 使用示例

### 基本單位操作
```cpp
// 初始化系統
UnitManager->InitializeUnitManager(World);

// 選擇單位
UnitManager->HandleUnitSelection(ScreenPosition, bShiftPressed);

// 移動單位
UnitManager->MoveSelectedUnits(TargetPosition);

// 設置編隊
UnitManager->SetFormation(EFormationType::Line);
```

### 戰鬥操作
```cpp
// 註冊戰鬥單位
CombatSystem->RegisterCombatUnit(Unit, Stats);

// 開始攻擊
CombatSystem->StartAttack(Attacker, Target);

// 設置敵對關係
CombatSystem->SetUnitRelationship(UnitA, UnitB, true);
```

### AI控制
```cpp
// 初始化AI
AIController->InitializeAIController(World, Unit);

// 設置AI參數
FAIParameters Params;
Params.AIType = EAIType::Aggressive;
AIController->SetAIParameters(Params);

// 處理威脅
AIController->HandleThreatDetection(Threat);
```
