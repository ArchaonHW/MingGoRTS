## 🎮 使用示例

### 基本本地化操作
```cpp
// 設置語言
LocalizationSystem->SetLanguage(ELanguage::ChineseS);

// 獲取本地化文本
FString LocalizedText = LocalizationSystem->GetLocalizedText(TEXT("UI_OK"), TEXT("OK"));

// 格式化本地化文本
TArray<FString> Args = {TEXT("Player1"), TEXT("100")};
FString FormattedText = LocalizationSystem->GetFormattedLocalizedText(TEXT("UI_PLAYER_SCORE"), Args);
```

### 文化格式化
```cpp
// 格式化日期
FString DateStr = LocalizationSystem->FormatDate(FDateTime::Now());

// 格式化貨幣
FString CurrencyStr = LocalizationSystem->FormatCurrency(100.50f, TEXT("USD"));

// 格式化數字
FString NumberStr = LocalizationSystem->FormatNumber(1234.56f, 2);
```

### 翻譯管理
```cpp
// 添加翻譯
LocalizationSystem->AddTranslation(TEXT("UI_NEW_BUTTON"), ELanguage::ChineseS, TEXT("新按鈕"));

// 批量翻譯
TArray<FLocalizationData> Translations;
// 填充翻譯數據
LocalizationSystem->BatchAddTranslations(Translations);

// 自動翻譯
LocalizationSystem->AutoTranslate(TEXT("UI_NEW_FEATURE"), ELanguage::Japanese);
```

### 藍圖使用
```cpp
// 在藍圖中使用
FString LocalizedText = UMingRTSLocalizationBlueprintLibrary::GetLocalizedText(TEXT("UI_OK"));
FString DateStr = UMingRTSLocalizationBlueprintLibrary::FormatDate(FDateTime::Now());
```
