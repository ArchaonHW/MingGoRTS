## AI 生成技術規格

### 圖像生成

| 工具 | 建議 | 參數 |
|------|------|------|
| Stable Diffusion | 主要工具 | 1024x1024, CFG 7-8, Steps 30-50 |
| Midjourney | 備選 | --ar 16:9, --v 6, --style raw |
| DALL-E 3 | 快速原型 | 1024x1024, vivid style |

**風格關鍵詞:**
- Chinese Republican era 1912-1949
- Vintage photography style
- Sepia tone / Film noir atmosphere
- Cinematic documentary quality
- Historical authenticity

### 音樂生成

| 工具 | 建議 | 參數 |
|------|------|------|
| MusicGen | 主要工具 | 32kHz, 30-120s duration |
| AIVA | 備選 | Classical/Traditional Chinese preset |
| Suno | 快速原型 | 120 BPM, Epic cinematic style |

**音樂風格關鍵詞:**
- Chinese traditional instruments (erhu, pipa, guzheng)
- Western orchestra hybrid
- Military brass and percussion
- Republican era documentary style

### 音效生成

| 工具 | 建議 | 參數 |
|------|------|------|
| ElevenLabs Sound Effects | 主要工具 | High quality, specific prompts |
| Freesound + AI | 備選 | 混合編輯 |
| Splice | 商業 | 專業音效庫 |

**音效規格:**
- Format: WAV (44.1kHz, 16-bit)
- 3D音效: 單聲道 + 3D定位
- UI音效: 立體聲
- 環境音效: 循環無縫

### 影片生成

| 工具 | 建議 | 參數 |
|------|------|------|
| Runway Gen-2 | 主要工具 | 1080p, 24fps |
| Pika Labs | 備選 |  cinematic style |
| HeyGen | 角色影片 | AI avatar, lip-sync |

**影片規格:**
- Resolution: 1920x1080 (1080p)
- Frame Rate: 24fps
- Format: MP4 (H.264)
- Duration: 15-90 seconds

## 素材命名規範

### 檔案命名格式

```
[EpicID]_[AssetType]_[Category]_[Name]_[Variation].[Extension]

範例:
- epic1_image_bg_decision_01.png
- epic2_music_battle_epic.wav
- epic3_sfx_ui_levelup.wav
- epic6_video_marketing_crossplatform.mp4
```

### 目錄結構

```
Content/
└── EpicAssets/
    ├── epic1/
    │   ├── images/
    │   ├── music/
    │   ├── sfx/
    │   └── video/
    ├── epic2/
    ...
```

## 生成工作流程

### 1. 初始化系統

```powershell
# 第一次使用
.\Tools\ai\epic_assets_generate.ps1 -Init
```

### 2. 批次生成

```powershell
# 生成所有 Epic 的所有素材
.\Tools\ai\epic_assets_generate.ps1 -All

# 生成特定 Epic
.\Tools\ai\epic_assets_generate.ps1 -Epic epic2

# 只生成音樂
.\Tools\ai\epic_assets_generate.ps1 -All -Type music

# 強制重新生成
.\Tools\ai\epic_assets_generate.ps1 -Epic epic1 -Force
```

### 3. 查看進度

```powershell
# 列出所有 Epic 素材需求
.\Tools\ai\epic_assets_generate.ps1 -List
```

### 4. 清理素材

```powershell
# 刪除所有生成的素材
.\Tools\ai\epic_assets_generate.ps1 -Clean
```

## 品質檢查清單

### 圖像素材
- [ ] 解析度符合規格
- [ ] 風格統一（民國時期）
- [ ] 無版權問題
- [ ] 透明背景（精靈圖）
- [ ] 壓縮優化（PNG/WebP）

### 音樂素材
- [ ] 時長符合規格
- [ ] 循環無縫（背景音樂）
- [ ] 音量標準化 (-14 LUFS)
- [ ] 無雜音/剪峰
- [ ] 民國風格元素

### 音效素材
- [ ] 44.1kHz, 16-bit WAV
- [ ] 音量適中（UI: 0.6-0.8, Combat: 0.8-1.0）
- [ ] 3D音效正確設定
- [ ] 循環點無縫
- [ ] 多變體隨機性

### 影片素材
- [ ] 1920x1080, 24fps
- [ ] H.264 編碼
- [ ] 音畫同步
- [ ] 字幕/標題（如需要）
- [ ] 品牌一致性
