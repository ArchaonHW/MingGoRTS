# MingGoRTS 專案計劃文檔

## 📋 專案概述

### 專案名稱
MingGoRTS - 民國時期即時戰略遊戲

### 專案愿景
打造一款融合歷史文化與現代 AI 技術的創新 RTSS 遊戲，為玩家提供沉浸式的民國時期戰略體驗。

### 專案目標
- **短期目標**: 完成核心遊戲循環，實現可玩的 Alpha 版本
- **中期目標**: 完善所有主要功能，發布穩定的 Beta 版本  
- **長期目標**: 全球發布，建立持續更新的遊戲生態系統
