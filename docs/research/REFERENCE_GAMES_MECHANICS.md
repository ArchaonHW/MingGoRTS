# 參考作機制萃取 → MingGoRTS 對照研究

**目的**：以 Total War / Mount & Blade / Hearts of Iron IV / ELIN
四款參考作訓練本專案的設計方向——萃取各作的招牌機制，
對照現有引擎能力（BattleController/Doctrine/QuantumFog/
BattleResources/Roster/BattleRecorder/BattleMap），產出佇列項。

**狀態**：done（產出層級 G 佇列項）

**定位共識**：本專案已是「回合規劃層 × 即時戰鬥層」hybrid——
正是 Total War 戰役/戰鬥雙層與 HOI4 計畫-執行的交會。
四作的取法：取機制不取皮相，每項都要能落進既有系統。

## Total War（戰鬥層深度）

| 機制 | 本專案現況 | 佇列 |
|---|---|---|
| 士氣連鎖潰逃：潰兵會拉低鄰近友軍士氣造成連鎖崩盤 | Squad 有 morale/routing 但無傳染 | **G-1**（S） |
| 疲勞：奔跑/交戰耗體力，疲憊降攻防速 | 無 | **G-3**（S） |
| 兵種克制三角 + 交戰修正 | Squad 無兵種欄位 | **G-2**（M） |
| 地形加成（高地/森林伏擊/泥濘減速） | FlowField 只記可通行性，無地形標記 | **G-4**（M） |
| 戰前部署階段 | `BattlePhase::Deployment` 已有 | 已涵蓋 |

## Hearts of Iron IV（規劃層深度）

| 機制 | 本專案現況 | 佇列 |
|---|---|---|
| 作戰計畫：畫箭頭/戰線 → AI 依計畫執行 + 計畫加成 | Doctrine 規則集已是「計畫」，缺的是「畫面→規則」的 UX | **G-5**（XL，依賴 A-1） |
| 師團編制器：模板化部隊（組成/成本/用途） | Squad 手刻、無模板 | **G-6**（L） |
| 情報戰：偵查/密碼/欺敵影響戰場 | QuantumFog + 情報點已在玩這個 | 已涵蓋（Q 層延伸） |
| 戰線寬度：同時交戰的兵力上限 | 無 | 併入 G-2 |
| 研究樹/國策 | 無 meta 層 | 併入 G-9 |

## Mount & Blade（玩家親歷與戰後）

| 機制 | 本專案現況 | 佇列 |
|---|---|---|
| 玩家將軍親臨戰場（可控英雄單位） | 無英雄單位概念 | **G-8**（L，依賴 A-4/E4-3） |
| 同伴 NPC 帶隊（多支部隊協同） | EnemyGeneral 是敵方版；我軍可同理 | 併入 G-6 |
| 戰後處置：戰利品、傷兵恢復 vs 陣亡 | Roster 有名冊但無戰後流轉 | **G-7**（M） |
| 第一人稱戰鬥 | 與俯視 RTS 定位衝突 | **拒絕** |

## ELIN（meta 循環與程序生成）

| 機制 | 本專案現況 | 佇列 |
|---|---|---|
| 基地建設/整補循環（戰鬥間的養成層） | 無 meta 層 | **G-9**（XL） |
| 程序生成地圖 | NeuralTerrainGen 已能產 heightmap；BattleMap 有 JSON schema | **G-10**（M）——現成接合點 |
| 居民工作指派 → 資源產出 | 可映射為戰後兵員/裝備補充 | 併入 G-9 |
| 生存/食物維持費 | 規模過大，本專案是戰鬥原型 | **拒絕** |

## 建議批次順序

1. **小步快跑批**：G-1 連鎖潰逃（味道最足、最小）→ G-3 疲勞
2. **戰鬥深度批**：G-2 兵種克制+戰線寬度 → G-4 地形
3. **meta 批**：G-7 戰後流轉 → G-6 編制器 → G-9 基地循環
4. **UX 批**：G-5 作戰計畫箭頭（等 A-1 UI 落地）
5. **生成批**：G-10 程序戰場（NeuralTerrainGen 現成）
6. **英雄批**：G-8 將軍親臨（等可玩 demo 穩定）

## 誠實性聲明

- 萃取的是**機制設計**，非美術/敘事/授權內容。
- G-5/G-8/G-9 是 XL/L 大項，未 spec 前不得開工（workflow 規則）。
- 拒絕項理由：第一人稱戰鬥與俯視 RTS 衝突；ELIN 生存模擬
  超出本專案戰鬥原型定位。
