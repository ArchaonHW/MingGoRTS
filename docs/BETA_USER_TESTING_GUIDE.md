## 🔍 問題報告指南

### 問題分類
1. **崩潰問題** - 遊戲完全無響應或退出
2. **功能缺陷** - 功能無法正常工作
3. **性能問題** - 幀率低、加載慢、卡頓
4. **UI問題** - 界面顯示錯誤、操作無響應
5. **音頻問題** - 聲音異常、無聲、音質差
6. **網絡問題** - 連接失敗、同步錯誤
7. **兼容性問題** - 特定設備或系統不兼容
8. **平衡性問題** - 遊戲難度、資源平衡等

### 問題報告格式
```
📋 問題標題: [簡短描述問題]

🎯 問題類型: [崩潰/功能缺陷/性能/UI/音頻/網絡/兼容性/平衡性]

🖥️ 系統信息:
- 操作系統: [Windows 11/Android版本/iOS版本]
- 硬件配置: [CPU/GPU/RAM/存儲]
- 遊戲版本: [Beta v1.0.0]

📝 問題描述:
[詳細描述問題現象]

🔄 重現步驟:
1. [步驟1]
2. [步驟2]
3. [步驟3]
...

🎯 期望結果:
[描述應該發生的正常情況]

❌ 實際結果:
[描述實際發生的問題]

📎 附加信息:
[截圖、視頻、日誌文件等]

🔥 嚴重程度: [嚴重/影響體驗/輕微/建議]
```

### 日誌收集
崩潰問題請提供以下日誌文件：
- Windows: `%LocalAppData%/MingGoRTS/Saved/Logs/`
- Android: `/Android/data/com.minggorts/files/Logs/`
- iOS: 通過iTunes文件共享獲取
