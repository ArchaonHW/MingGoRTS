# MingGoRTS 用戶手冊 / MingGoRTS User Manual

## 🎮 歡迎來到 MingGoRTS / Welcome to MingGoRTS

### 遊戲簡介 / Game Introduction

MingGoRTS 是一款設定在中國民國時期的即時戰略遊戲，融合了歷史背景與現代遊戲機制。玩家將扮演一位在民國時期崛起的領袖，通過建設基地、管理資源、訓練軍隊、發展經濟，最終統一亂世。

MingGoRTS is a real-time strategy game set in the Republican era of Chinese history, blending historical background with modern game mechanics. Players will take on the role of a leader rising during the Republican era, unifying the chaotic times through base construction, resource management, army training, and economic development.

## 🎯 遊戲目標 / Game Objectives

### 主要目標 / Main Objectives

1. **統一全國 / Unify the Nation**
   - 征服所有敵對勢力 / Conquer all hostile forces
   - 建立統一政府 / Establish a unified government
   - 實現國家繁榮 / Achieve national prosperity

2. **發展經濟 / Develop Economy**
   - 建設繁榮城市 / Build prosperous cities
   - 發展貿易路線 / Develop trade routes
   - 維持經濟平衡 / Maintain economic balance

3. **培養軍隊 / Train Military**
   - 訓練精銳部隊 / Train elite forces
   - 研發先進武器 / Research advanced weapons
   - 建立防禦工事 / Build defensive structures

4. **外交策略 / Diplomatic Strategy**
   - 建立同盟關係 / Establish alliance relationships
   - 處理外交事務 / Handle diplomatic affairs
   - 維護國際聲譽 / Maintain international reputation

   - 假裝撤退 / Feign retreat
   - 設置埋伏 / Set ambush
   - 包圍敵人 / Surround enemy

3. **堅守要點 / Hold Key Points**
   - 保護重要建築 / Protect important buildings
   - 控制戰略位置 / Control strategic positions
   - 阻止敵人突破 / Prevent enemy breakthrough

##### 進攻戰術 / Offensive Tactics

   - 集中優勢兵力 / Concentrate superior forces
   - 突破敵人防線 / Break through enemy defense
   - 快速擴大戰果 / Quickly expand gains

2. **側翼包抄 / Flank Attack**
   - 主力正面牽制 / Main force frontal containment
   - 側翼迂迴包抄 / Flank detour and encirclement
   - 切斷敵人退路 / Cut off enemy retreat
