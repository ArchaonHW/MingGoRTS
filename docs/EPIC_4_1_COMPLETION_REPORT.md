## 🎮 使用示例

### 基本UI操作
```cpp
// 創建UI元素
FString ElementID = UISystem->CreateUIElement(EUIType::Main, TEXT("MainUI"), FVector2D(0, 0), FVector2D(1920, 1080));

// 設置UI主題
UISystem->SetUITheme(EUITheme::Dark);

// 顯示UI元素
UISystem->ShowUIElement(ElementID, EUIAnimation::Fade);

// 響應式佈局調整
UISystem->AdjustResponsiveLayout(FVector2D(1920, 1080));
```

### 基本音頻操作
```cpp
// 創建音頻軌道
FString TrackID = AudioSystem->CreateAudioTrack(TEXT("BackgroundMusic"), EAudioType::Music, MusicAsset);

// 設置音頻情感
AudioSystem->SetAudioMood(EAudioMood::Calm);

// 播放音頻
AudioSystem->PlayAudioTrack(TrackID, EAudioTransition::Fade);

// 設置3D音頻位置
AudioSystem->Set3DAudioPosition(TrackID, FVector(100, 200, 50));
```
