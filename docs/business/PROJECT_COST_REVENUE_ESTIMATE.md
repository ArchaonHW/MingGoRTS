## 2. 總成本預估

### 2.1 人力成本（最大項）

以台灣遊戲業初–中階開發者全成本（薪資+勞健保+管理費）約 **每月 8–12 萬 TWD/人** 計，
本估算取 **10 萬/人月**。

| 階段 | 工作量 | 人力成本 |
|---|---|---|
| MVP（斷橋） | 2–3 人月 | 20–30 萬 |
| 垂直切片 | 6–8 人月 | 60–80 萬 |
| 完整版（EA→正式） | 18–24 人月 | 180–240 萬 |
| **小計** | **26–35 人月** | **260–350 萬** |

> 已投入成本（引擎+IDE+AI 系統，約 2 萬行程式碼）不計入本表——
> 屬沉沒成本，且引擎資產可複用於後續專案。

## 3. 總收益預估

### 3.1 定價模型

同類參照：獨立戰術/RTS（《Wargroove》《Fights in Tight Spaces》《鐵甲雄風》類）
Steam 定價 **$14.99–24.99 USD**。本作機制獨特但受眾待驗證，
建議 **$19.99 USD（約 620 TWD）**，EA 期間 $14.99。

### 3.2 單位淨收益

| 項目 | 金額（USD/套） |
|---|---|
| 定價 | 19.99 |
| Steam 抽成 30% | −6.00 |
| 退貨/VAT/區域定價折損（約 15%） | −3.00 |
| **實收淨額** | **≈ 11.0（≈340 TWD）** |

### 3.3 銷量情境

「寫作戰鬥」定位新穎——上無天花板參照，下有保障型下限。三情境：

| 情境 | 銷量 | 總收益（TWD） | 說明 |
|---|---|---|---|
| **保守** | 5,000 套 | ≈ 170 萬 | 小眾核心向，口碑平平 |
| **基準** | 25,000 套 | ≈ 850 萬 | Steam 好評率 >80%、Next Fest 轉換正常 |
| **樂觀** | 100,000 套 | ≈ 3,400 萬 | 華語圈話題作 + 實況擴散 |

### 3.4 收支平衡點

```
完整版成本（基準 ~500 萬）÷ 單位淨收益 340 TWD ≈ 14,700 套
```

**回本門檻約 1.5 萬套** —— 對 Steam 策略類而言屬「中等偏易」門檻，
前提是垂直切片先證明核心循環成立。

## 4. 風險與決策點

1. **最大風險 = 受眾重疊度**（Party Mode 已識別）：寫腳本玩家 ∩ RTS/RPG 玩家
   未知數大。**垂直切片是第一個 go/no-go 點**：若 Demo 願望清單轉換率低於
   同類中位數，止損在 110 萬內。
2. **敵將手寫成本**：每個名將是精雕謎題，8–10 章的內容成本是人力表的主變數。
3. **引擎自研的雙面性**：省去授權費且完全可控，但所有工具鏈成本自負——
   已投入的引擎開發攤提到本專案約可降低後續專案 30–50% 成本。
4. **里程碑制支出**：建議按 MVP → 切片 → 完整版分段解鎖預算，
   每段設量化驗收（如切片 Demo 願望清單 ≥ 3,000 再投完整版）。
