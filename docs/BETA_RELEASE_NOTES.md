## 📋 發布概述

MingGoRTS是一款基於Unreal Engine 5開發的即時戰略遊戲，設定在中國民國時期。經過完整的系統集成測試，所有核心功能已達到Beta版本發布標準。

### 🎯 遊戲特色
- **歷史背景**: 設定在中國民國時期的RTS遊戲
- **核心玩法**: 大規模單位控制、資源管理、基地建設
- **AI系統**: 智能AI對手和戰役模式
- **跨平台**: 支持Windows、Android、iOS
- **AI內容生成**: 使用Stable Diffusion和AIVA生成遊戲資產
